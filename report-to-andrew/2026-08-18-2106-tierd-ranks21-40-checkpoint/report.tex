\section*{Rank 29: portable compaction-order repair}
Before conflict 1000, Tactix and Kissat had the same directed binary order.
Reduce-time variable compaction reconstructed both directions from one
undirected stream and reversed the order. Preserving each directed prefix
repaired that frontier, but the run still timed out. Continued common-state
tracing exposed two later representation defects.

First, a replacement inherited its source's stable position but remained
physically appended behind later clauses. Second, Reduce marked victims before
sparse collection, while the collector ran only when root simplification
changed some other clause. Thus pre-existing garbage could survive and the
expected rewatch never happen. The accepted general repair collects for either
pre-existing garbage or root rewriting, replays the swept tail by persistent
source-position key, and stably partitions irredundant before redundant
clauses. Tests use synthetic mixed tails and contain no benchmark, rank,
literal, conflict, hash, or deadline identity.

\section*{First N2 hypothesis and focused falsification}
The rejected proof contains hundreds of deletion lines for clauses the checker
no longer holds. The common large-clause retirement primitive wrote a proof
deletion before testing whether its arena record was already garbage. A second
retirement was therefore an idempotent solver-state no-op but a second checker
mutation. This is especially dangerous in DRAT: deletion is keyed by literals,
so the surplus line can consume a different live duplicate and make a later
unit cease to be RUP.

The first production repair checks the garbage bit before emitting the
deletion, making the whole retirement transition idempotent. Sparse collection
also drops a deferred OTFS reason if another rule already retired it; its dead
\code{searched} word is a cursor, not a forwarding reference. Generic tests
cover exactly one deletion for duplicate literals and safe collection of a
retired deferred reason.

An optional diagnostic build feature shadows the checker's live clause
population and aborts at the first unbacked deletion. It is armed only after
the frontend has seeded the full input population, and production builds
compile its emission hooks out. The rebuilt shadow suite passes 72/72; Release,
Trace, and ASAN-O3 pass 72/72, 71/71, and 72/72.
