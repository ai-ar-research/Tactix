\section*{Executive summary}
A new Claude skill asks Codex to review Tactix documentation without modifying
the repository. Codex must return findings, a complete KEEP/COMPACT/DELETE
classification, and a proposed patch. Claude and the user retain approval over
every change, with separate approval required for deletions.

\section{Findings and results}
The skill covers \texttt{CLAUDE.md}, \texttt{DEVELOPMENT\_PLAN.md},
\texttt{PROGRESS.md}, the living documents, every tracked
\texttt{docs/design/*.md}, and the documentation Python scripts. It requires
preservation of N1--N4, complete proof-rule contracts, active work, exact
defaults, deviations, reopening conditions, and machine-parsed structures.

Design documents and scripts receive exactly one disposition: KEEP, COMPACT,
or DELETE. Insufficient evidence means KEEP. A deletion proposal must identify
all references, migrate every unique current fact, and update references in the
same patch.

The obsolete \texttt{tools/docs/archive-log.py} was removed. It served only
checkouts predating plan revision 97; current PROGRESS has no narrative Log,
and the script was absent from both CTest and wrap-up. The active checkers were
retained as stable executable specifications rather than regenerated by agents.

\section{Evidence}
The new skill is
\texttt{.claude/skills/codex-revisit-docs/SKILL.md}; it passed the skill-format
validator and is below the repository's default skill-size budget. References
to the retired archiver were removed from \texttt{docs/log/README.md},
\texttt{tools/docs/check-progress.py}, and
\texttt{tools/docs/check-comment-hygiene.py}. No checker meta-test or new CTest
was added, following Andrew's direction to avoid spending time testing the
checker scripts.

\section{Risks and decisions}
Codex runs with a read-only sandbox and may only propose an
\texttt{apply\_patch} patch. This prevents an external documentation review from
overwriting active work. The existing Python checkers remain narrow structural
oracles; the skill tells Codex to KEEP or COMPACT an imperfect checker unless
its underlying invariant is genuinely obsolete.

\section{Next actions}
Invoke \texttt{codex-revisit-docs} when a documentation audit is desired.
Review its evidence and classification before considering the patch. Apply no
DELETE disposition without explicit user approval.
