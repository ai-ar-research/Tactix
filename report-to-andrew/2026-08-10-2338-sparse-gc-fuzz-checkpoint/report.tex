\section*{Executive summary}

The open P4-CVG \code{mod4block} investigation reached a strong but held
candidate. The conflict-1010 trajectory split was caused by sparse Reduce
collection resetting the replacement-search cursor of clauses in the preserved
irredundant prefix. \kissat{} retains that cursor and the existing prefix watch
order. The candidate makes \tactix{} preserve both, including when earlier
garbage changes prefix arena offsets.

The result is material: the trace-off production pin solves \code{mod4block}
with an independently verified SAT model in 31.87 seconds, where the preceding
shipped pin timed out at 120 seconds; \kissat{} takes 18.60 seconds. A matched
trace reproduces the target cursor sequence and keeps decisions and learned
sets aligned through conflict 1012.

The candidate is not accepted. The required quick fuzz run fails tracked
corpus cases 004 and 005 before reaching the 300 generated inputs. One failure
is an ASan out-of-bounds read in Sweep after Factor creates extension variables;
the other passes an out-of-range literal to proof serialization. These are
consistent with one invalid arena-reference lifecycle, but that attribution is
not yet proved. In addition, the earlier \code{tr-n300-s055} fixture solves
proof-clean in 36.43 seconds at a 120-second limit but misses its required
30-second cumulative guard.

\section{Implementation decision}

Sparse collection now treats \code{watch_start} as a semantic boundary rather
than only an optimization hint:

\begin{itemize}[leftmargin=*]
  \item copied prefix clauses retain \code{Clause::searched};
  \item live prefix watch entries retain order and blocker while their Refs are
        forwarded around removed prefix garbage;
  \item the relocated tail boundary is computed after compaction; and
  \item only tail clauses reset their cursor and receive rebuilt watches.
\end{itemize}

Optional paired trace fields
\code{TACTIX_EVENT_TRACE_WATCH_POSE} and
\code{KISSAT_EVENT_TRACE_WATCH_POSE} expose the physical literal pose and
cursor. They are compiled only into trace builds. Focused tests cover cursor
preservation, prefix garbage, reference forwarding, tail rewatching, and trace
output.

\section{CI quota change}

The GitHub Actions workflow no longer runs the full sanitizer, checker, and
fuzz matrix on every push and pull request. It is scheduled weekly (Monday at
06:17 UTC), remains manually dispatchable, and cancels an older run for the
same ref. This deliberately bounds routine Actions-minute consumption while
retaining an explicit milestone gate.
