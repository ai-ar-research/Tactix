\section*{Executive outcome}
Current/current Rank-27 profiling localized a portable common-state throughput
loss in Kernel representation: after variable compaction, Tactix repeatedly
comparison-sorted every live variable to reconstruct the permanent DIMACS
first-occurrence order.  At the exact conflict-9450 boundary this helper alone
accounted for 3.2251\% of production cycles.  The general repair records the
inverse first-occurrence permutation once, retains retired external identities
as holes, and resolves surviving entries through the existing
external-to-internal compaction map.  Direct Kernel clients keep the previous
fallback order.  No proof rule, strategy decision, scheduling cadence, effort
budget, or benchmark-specific arm changes.

The repaired profile preserves every non-time counter and removes 411 ms total
and 402 ms inprocessing by conflict 9450.  Its event trace is byte-identical to
the accepted current-Tactix trace, including exact rule boundaries,
candidate/order images, logical ticks and costs, scheduling order, and resulting
learning and pruning.  The mandatory full frozen Tier B plus five predeclared
mechanism-relevant Tier C guard passes 66/66 with independently checked models
and proofs, no solve loss, and zero certificate residue.  Exact-source sanitizer
fuzz passes 10,000 cases with zero failures.  The checked immutable Rank-27
witness preserves every non-time counter and identical proof bytes while
improving 548.645 to 413.830 internal seconds.  This is a 134.815-second
same-trajectory recovery, but the 300-second objective remains open.

\section*{General repair and exact-state evidence}
Kernel now stores an inverse vector from permanent import rank to external
variable, complementing its existing external-rank vector.  First import
appends one external identity.  Reconstruction traverses that stable vector, skips retired
holes through \code{external_to_internal}, then appends any unrecorded live
direct-client variables in stable external order.  The previous semantics are
therefore unchanged before and after compaction, but the recurring
$O(n\log n)$ comparison sort becomes a linear image traversal.  A focused
Kernel regression imports variables in non-numeric order, retires one imported
and one unrecorded identity, compacts, and checks the exact surviving order and
all Kernel invariants.
