\section{Executive outcome}

The remaining Rank-34 conflict-7,705 formula divergence has been localized and
repaired.  Pinned Kissat immediately learns a unit when TransitiveReduce finds
a failed source literal, after retaining reductions already proved for that
source.  Tactix found the same failed walks but discarded the earlier
tombstones and deferred the units to Probe.  Tactix now matches the reference
lifecycle and emits a native-LRAT BFS chain for each failed-source unit.

The repair closes the exact local state and materially improves the current
Rank-34 baseline: 1,014.550 seconds falls to 804.709 seconds with a verified
model.  It does not recover the earlier 616.624-second trajectory or Kissat's
344.045 seconds.  A uniform Rank 1--40 candidate solves all 40 instances, but
totals 10,573.791 seconds versus 9,305.953 for the preceding homogeneous
candidate.  The general repair remains retained; the 13.6\% aggregate
regression is a downstream mechanism/trajectory problem, not grounds for a
formula or rank gate.

\section{Exact causal evidence}

Both solvers entered the second conflict-7,705 TransitiveReduce pass with the
same duplicate-sensitive 3,378-copy binary multiset.  Tactix removed 41 copies
and Kissat 39.  The only excess Tactix deletions were
\code{(-19396 v 19343)} and \code{(-19788 v 19343)}.

Selected-pair tracing showed the precise chronology.  Kissat processes sources
\code{-19788} and \code{-19396} before source \code{19343}.  Each first walk
reaches both polarities, so Kissat immediately fixes the source.  Source
\code{19343} then sees both destinations fixed and admits five candidates.
Tactix deferred both units, admitted seven candidates for source \code{19343},
and deleted the two extra binaries.

Pinned \code{transitive.c} confirms that its failed branch compacts earlier
reductions, calls \code{kissat\_learned\_unit}, and propagates before continuing.
This is an unconditional rule lifecycle, not a scheduling heuristic.

\section{Repair and correctness}

The Tactix BFS now records the id of each live binary that first reaches a
literal.  Under native LRAT, that propagation order is the RUP hint chain for
the new unit; the contradiction-closing edge is last.  Earlier deletions are
committed, the failed source is assigned, and the canonical or dosed surface
reaches root before the next source.  DefaultPolicy owns propagation and H
publication; TransitiveReduce continues to own only its semantic and proof
delta.

Causal job 1657559 makes all four begin/end binary snapshots exact, with counts
3,355, 3,312, 3,378, and 3,339.  It emits units \code{-19788} and
\code{-19396} in the second pass and finishes with the same 14,378 active
variables and 14,259 heap entries as Kissat.

\section{Decision and next work}

Retain the TransitiveReduce repair and every other causally proved general
repair.  Do not promote the current aggregate as a performance acceptance and
do not restore a hidden CaDiCaL heuristic or formula-specific profile.  The
next convergence pass should localize the earliest common-state owner shared by
the large R17/R19/R21 regressions, then return to Rank 34's inherited
pre-Eliminate heap pose.  Factor and formula classification remain downstream
or exonerated.

Memory remains a parallel representation priority: Rank 10 is near 17 GiB and
several medium instances remain two to three times Kissat's RSS.  The current
checkpoint nevertheless satisfies the requested implementation closure,
homogeneous coverage run, codebase revisit, durable progress update, and major
Andrew report.
