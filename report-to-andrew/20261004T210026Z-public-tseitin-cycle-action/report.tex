\section*{Controller-visible component choice}

The bounded native census returns every eligible connected XOR component as a
separate exact \code{tcx2:} payload. It does not privately choose which
component the controller receives. The payload commits the stored clauses,
native proof identities, variable mapping, root image, admitted XOR groups,
incidence, available-edge cycle, X7 witness, transaction, and limits. A
distinct \code{tcd1:} identity records semantic duplicate state in one
Kernel-bound session.

Apply recaptures the formula, selects only the named component, rebuilds the
complete plan, and exact-matches it before mutation. Success publishes one
cycle-breaking unit. Propagation remains a separate action. A fresh census at
the next propagated root can expose another component or an alternative cycle.
Root-fixed off-cycle edges are authenticated; selected cycle edges must remain
unassigned.

The present domain is conservative: any unclaimed stored clause touching a
component edge excludes the component, even when root-satisfied. This physical
residual boundary is stronger than the abstract X7 condition and remains an
explicit N1 review item.

\section*{Proof, provenance, and retry behavior}

Native DSR emits two temporary helpers, one RUP unit, two deletions, and one
proof-only variable. It adds no branchable auxiliary and needs no model
reconstruction witness. DRAT, LRAT, and PBP decline before mutation. This keeps
the first public route in the default DSR proof vocabulary without adding a
rule-specific pseudo-Boolean path.

The prebuilt JSONL record binds action and semantic identities, typed limits,
the mapping and authenticated root units, exact source occurrences and proof
IDs, the cycle and witness, proof events, installed unit, projection/deletion
state, and exact effort and proof volume. Failed publication neither consumes
the duplicate key nor closes the certificate boundary.

Applied, duplicate, and complete no-structure outcomes consume the offer.
Invalid, inapplicable, unsupported-proof, and stale results discard it until
context changes. Exhaustion and interruption retain it while suspending
eligibility; an explicit profile-only change retries it without rediscovery.
Formula, session, or owner changes discard it. There is no fallback or rollback.
