\section*{Objective and outcome}
The requested work was to finish the Vivify parity investigation---including
candidate scheduling, literal order, and interleaving with surrounding proof
rules---then report the verified result.  The Vivify repair itself remains
closed: candidate scope, cumulative tier budgets, jumped-reason deduction,
terminal effects, and productivity match the retained Kissat evidence.  The
first portable divergence after those calls was the TransitiveReduce pass
between them.

Tactix processed V4 sources in ascending literal order.  Kissat activity-sorts
them, and its literal source contains an unusual but observable detail: the
stack holds variable indices, while the comparator applies \code{IDX} again
before reading EVSIDS/VMTF activity, sorts increasing, then pops from the back.
Tactix now poses the equivalent rule-local order for its front-consumed array.
No input name, hash, rank, literal, deadline, or tuned constant enters the
solver.  Early BFS exit was tested separately and left unchanged because it
was inert at the localized boundary.

Release passes 72/72.  The required matched 28B+5C guard is 66/66 valid, with
all SAT models and UNSAT proofs checked and no certificate residue.  The new
rank-27 witness still returns UNKNOWN at 1,200.004 seconds, so this is a
source/scheduling repair rather than a Tier-D closure.

\section*{Localization from the matched Vivify state}
The repaired trace reaches the same conflict-3069 Probe trigger and restores
both Vivify long-clause populations and aggregate terminal effects.  The first
later decision mismatch was traced backward from decision level 35.  EVSIDS
scores matched, but heap topology did not: the Probe pipeline removed 369
Kissat variables versus 33 Tactix variables.  Slot snapshots made the first
formula owner the TransitiveReduce call between the Vivify calls.

The retained source comparison separated three mechanics: mode-dependent
activity order versus ascending literals, early destination exit versus a
complete BFS, and Kissat's second \code{IDX} conversion on a scheduled variable
index.  Two bounded Tactix-only experiments isolated them.

Job \code{1637470} tested native order, early exit alone, an ordinary
own-variable heuristic order, and their combination.  Early exit was
bit-identical.  The ordinary heuristic changed work but deleted no binaries at
the boundary, so that candidate was reverted.

Job \code{1637474} then posed the literal reference comparator, both with and
without early exit.  The two arms were identical.  The first V4 call changed
from zero deletions to 24; the retained Kissat trace deletes 21.  Its ending
binary counts are 751,109 Tactix and 751,102 Kissat, reducing a ten-binary
pre-call excess to seven.  After the second Vivify they are 751,122 and
751,112.  Later Sweep/Substitute transitions make the counts close through
different equivalence and retained-root representations.  That is the next
open boundary; the evidence does not reopen Vivify deduction or V4 source
order.

\section*{Implementation decision}
The production change is deliberately narrow.

\begin{itemize}
\item Only TransitiveReduce interprets its heuristic arm through the reference
  \code{v >> 1} activity proxy and back-to-front tie semantics.
\item Because Tactix consumes from the front, it uses decreasing activity and
  a decreasing-variable tie, preserving positive-then-negative sign order.
\item The default V4 slot selects this order.  Other rules and candidate-order
  arms retain their prior meaning.
\item Early exit remains off because its one-at-a-time arm changed no formula
  state at the witness boundary.
\end{itemize}

The focused regression independently computes the best reference proxy and
requires that candidate first.  The slot test requires V4 to ship with the
reference activity arm.  Release's 72 tests include the TransitiveReduce
brute-force equivalence oracle and proof checks.  No unit test or fuzzing
exposed a crash or soundness defect, so the plan's mandatory Claude
repair-delegation trigger did not fire.
