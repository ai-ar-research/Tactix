\section*{Outcome}
The N4 scheduling ledger contained a stale open-case description. It said
Tactix visits only derived Sweep proof steps and cannot expose an original
clause that becomes a root unit in an extracted core. Source inspection shows
that commit \texttt{7a668e76} (12 September) added ordered clausal-core export,
original-row eligibility filtering, inline unit commitment, and a one-step
proof for an original clause. The ledger now says \emph{implemented;
acceptance open}. No solver semantics changed in this audit.

progress checks pass; the six pre-existing document-size reserve warnings
