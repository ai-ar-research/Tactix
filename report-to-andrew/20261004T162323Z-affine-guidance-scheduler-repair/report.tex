\section*{Objective and outcome}

This checkpoint evaluates the restored LymphoSAT affine constructor and the
new partial-model guidance path on the focused regression subset. It also
finishes three internal certified-UNSAT foundations and repairs the scheduler
lifecycle identified by the terminal result.

The result is useful but not accepted. All six unique MDP instances previously
solved directly by affine construction are recovered with independently checked
original-CNF models. Three search-trajectory controls are not recovered:
\texttt{cabp-V-nos6} is 4.6--5.1 times slower than the accepted reference,
\texttt{Break\_20\_72} times out at 1,200 seconds, and the WV2 timetable row
times out at 600 seconds. Partial-model guidance is never offered or consumed
on any focused row, so this campaign establishes no guidance benefit.

The causal audit finds that affine had been restored at the wrong lifecycle
boundary. The accepted source ran Lucky instance 8 as stage 0 of the
structured-root scheduler. The first repair called it directly before
\texttt{MaterializeColdState} and scheduler entry. Commit
\texttt{f6d7453f6} restores the typed stage and removes the direct call. Focused
normal and sanitizer tests pass; no benchmark in this report uses that new
commit yet.

\section*{Why the trajectories changed}

Accepted \texttt{d170b4a5} and latest saved good \texttt{6fe14539} have the
same \texttt{cabp} and Break decisions, conflicts, BVE work and structured-root
output. Rejected \texttt{156afef6b} and recovered \texttt{60446aa0d} share the
rejected prefix. On \texttt{cabp}, accepted execution applies no SR, eliminates
118,092 variables by BVE, and reaches 1,957,665 decisions and 86,308 conflicts.
The recovered execution adds 1,350 unique-literal AMO binaries, eliminates
845,002 variables, and reaches 6,635,734 decisions and 873,391 conflicts. Break
changes from zero SR applications to 31 ULC binaries. Timetable changes from
five SR applications and zero ULC binaries to 638 applications, 633 of them ULC
binaries.

The earliest plausible change is \texttt{84e8d197a}, which removed affine from
stage 0. Restoring only the affine call counter does not restore the accepted
structured prefix. The exact-one counter also changed from two to one, but the
removed second call ran after structured-root processing, so it cannot cause
that earlier divergence. This is strong endpoint and source-order evidence,
not a first-bad run at the intermediate commit.

Commit \texttt{f6d7453f6} now restores Lucky/8 as typed step 109 inside the
structured-root inprocessing scope. The configured affine parameters are posed
on that step, disabling affine removes it, and no second hidden call remains.
A feedback-level regression pins stage order, no-op disposition, unchanged
formula version, the expected strategy epoch transition, and later structural
execution. The combined checkpoint suite passes 10/10 in both normal and
ASan/UBSan builds, with leak detection disabled in the ptrace environment.

because the proof writer exposes no exact mutation epoch; one-shot apply/replay
is atomic.
\item Tseitin-cycle X7 has exact live replay and one DSR/no-proof root-unit
publication from XOR groups authenticated by the caller. Autonomous group discovery
and a public controller action remain absent.
\end{itemize}

The calculus and semantic-extension document now state these actual boundaries.
Every decline remains bounded and mutation-free; none is promoted to a public
learner-selectable capability yet.
