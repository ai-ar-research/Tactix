\section*{Certified GF(2) integration}

Commits \code{3787d6724}, \code{2b2d7ecb8}, and \code{405b56724} implement one
vertical slice of the requested architecture.  X9 \code{AffineConsequence}
owns an immutable pre-publication live-clause view, reduces a bounded GF(2)
basis, pages exact rows deterministically, and commits one selected row at a
propagated root.  Direct rows publish only missing parity CNF.  Wide rows now
publish a compact conservative Boolean extension rather than invoking a
private local-search solver.

Each wide transaction remaps its authenticated source equations into a dense
proof namespace, derives a balanced XOR network, and retains exactly the final
definition clauses and signed root unit.  Transition helpers that disappear
from the final network remain in the monotone namespace but are fixed true by
vacuous RAT units after an exact active-population check.  This prevents unused
helpers from becoming search decisions.  Every retained definition records
its output and two operands, so model reconstruction evaluates the XOR network
topologically and then omits the extensions.

The transaction records source occurrences, selected equation identities,
row/RHS, proof additions and deletions, distinct RAT roles, introduced and
proof-only helpers, projection, action identity, work, yield, and extent.
Preparation is mutation-free.  Source loss, stale ownership, unsupported proof
format, interruption, or any proof/work/namespace/journal bound declines
before publication.  Proof-on and proof-off paths allocate the same external
and kernel namespace.

The same exact direct or extended row is now available through additive C API
v9, deterministic replay, canonical DefaultPolicy execution, the opt-in
\code{gf2-affine} random-controller producer, and future learned-policy action
submission.  This preserves the N1 design: the learner chooses an ordinary
typed action rather than entering a separate solver.  M1 propagation and
semantic-variable advice remain separate follow-up actions.

Sixteen focused Debug tests pass across affine planning/publication, parity
proof lifecycle, C payload copying, replay, controller production, and noL
integration.  The exact two-source arity-eight wide fixture contains 15 source
variables, 256 input clauses, 13 retained definition variables, and 17 retired
helpers; its 972-lemma transaction proof is accepted by the pinned
\code{drat-trim} SAT-forward checker.  A separate contradictory width-eight
certificate is accepted as a full refutation.  Current limits are explicit:
broader overlap shapes, three-or-more-source rows, DSR checking of the wide
path, real fixed targets, full Debug, and all four regressions are still
pending for this new source.

\section*{noL and X17}

The Lucky/25 constructor remains diagnostic.  On \code{noL-11-10} and
\code{noL-11-4}, exact recognition fired repeatedly but both 600-second runs
timed out after roughly 0.75 billion search moves, without a model or consumed
partial guidance.  This confirms a search/publication miss rather than a
recognizer miss; it does not satisfy the Boolean-integration objective.

Commit \code{8d13ca87a} advances the certified route.  ULC now reauthenticates
the checker-visible live population, requires the unique irredundant ALO
source, chooses an unassigned endpoint, and emits pivot-first RAT through DSR
and DRAT.  X17 discovery replaces combination enumeration with a canonical
relation-clause index and durable bounded pages.  Focused Debug and Release
tests pass; a synthetic noL census finds 363 domains, 2,486 relations, 7,458
tuples, and 22,374 exact prefixes, and the ULC microproof passes independent
DSR and DRAT checking.  The two real noL targets have not yet been recovered.

\section*{What the evidence permits}

The accepted regression result says the pre-integration DefaultPolicy remains
strong and that the Ramsey Boolean transfer improved WV2 without a regression.
The new affine/noL work establishes certified, learner-selectable mechanics and
focused proof soundness.  It does not establish target effect or portfolio
superiority.  The fixed 36 and all 44 misses remain the authoritative recovery
obligation, with B28+C5, Rank1--50, WV100, WV2--89, full Debug, and both-policy
fuzz as preservation gates.

The next immutable checkpoint should first run full Debug, then probe the
highest-confidence affine rows: WV2-132 Tseitin, WV100-7 two-trees, WV100-51
MDP, rank 263 lightsout, and rank 569 \code{lec\_mult}.  The action log must
separate absent structure, offer rejection, proof-work exhaustion, successful
publication, and post-publication search effect.  Only after a coherent target
result should the four full regression campaigns be repeated.  Wider GF(2)
proof shapes and real noL X17 pages should be added from observed misses rather
than by indiscriminate constraint expansion.

The saved \code{d170b4a5} comparison remains the approved performance
authority and was not rerun.  DSR remains the default proof format.  A
rule-specific pseudo-Boolean route remains an option only if measured compact
clausal certification is impractical.
