\section{Outcome}

The Rank-10 memory regression is repaired and has completed the full promotion
evidence chain.  The accepted predecessor needed 19,886,212 KiB peak RSS on
the immutable Rank-10 input under SLURM-only memory enforcement.  The final
candidate needs 16,703,740 KiB, completes inside the strict 16-GiB task cgroup,
and preserves the exact recorded Rank-10 logical work.  The current
instrumented Kissat comparator uses 15,348,204 KiB, so the residual Tactix
excess is 8.83\%; it is now attributable to general retained import/order
structures rather than a duplicate formula-wide image.

The complete B28+C5 gate and the one Claude-owned consolidation fuzz campaign
both pass.  No correctness repair was needed.  The fresh Rank 1--40 screen is
also terminal and shows no memory or infrastructure exit under the corrected
SLURM-only contract.  It is not globally scorable because some solve and proof
checks timed out, but its individually validated pairs support the already
declared next order: Rank 4, then Rank 32.

\section{Source-backed localization and repair}

Matched boundary traces separated four representation owners from solver
behavior.  The repairs are general and contain no benchmark identity, rank,
deadline, or per-instance control.

\begin{enumerate}
  \item \textbf{Watch metadata.}  The exact full-width binary-watch count and
  the independent binary-first bit now share the existing 16-byte watch head.
  The encoding uses the identity
  \(\mathrm{words}=\mathrm{binaries}+2\,\mathrm{large}\), so count parity is
  already determined by word length.  All accepted conservative order-bit
  states remain representable and unchanged; this is important for N4 cost and
  scheduling parity.

  \item \textbf{Clause-order aliases.}  A mostly empty vector indexed by the
  global proof-ID space is replaced by fixed sparse pages.  Lookup remains
  exact and constant-time, including inherited replacement order.

  \item \textbf{Congruence liveness and closure.}  The duplicate full-key live
  binary table is replaced by a no-false-negative bit filter.  Every admitted
  query is confirmed against the authoritative smaller watch list, so stale
  positives after deletion affect cost only.  The exact value-occurrence index
  is built in the original registration order only when closure derives a unit
  requiring rescheduling; no-unit rounds omit it.

  \item \textbf{Sweep ledger.}  Sweep previously committed a 24-byte empty
  vector header for every one of 97,010,928 physical literals before reaching
  any environment.  The ledger is now keyed only by reached literal.  The map
  is never iterated, and each retained list preserves the same encounter order
  and contents.
\end{enumerate}

The compiled-only slot-memory diagnostic remains useful generic instrumentation
and has zero Release-build effect.  Unit coverage includes full-width watch
counts, conservative order-bit preservation, sparse alias lookup, liveness
filter false-negative exclusion, lazy Congruence behavior, and sparse Sweep
identity behavior.  All 76 Release tests pass, including proof, scheduling,
N1 boundary, rule-policy boundary, cleanup, and zero-overhead checks.

\section{Rank 1--40 screen and limitations}

The replacement screen at
\path{benchmarks/runs/20260827-0100-tierd-ranks1-40-slurm-memory-screen}
contains all 80 independent Tactix/current-Kissat tasks at \code{-c 12},
\code{--mem=48000M}, 1,200 seconds, and no address-space limit.  It has zero
correctness, infrastructure, cleanup, or certificate-residue failure.  There
are six Tactix solve timeouts and three solved-UNSAT checker timeouts; therefore
the complete campaign is correctly marked non-scorable rather than flattening
those invalid rows into solver losses.  Summary SHA-256 is
\code{6973ac74...ff396}.

Individually validated diagnostic UNSAT pairs include Rank 4 at
14.690/7.728 seconds (1.901x) and Rank 32 at 416.933/293.092 seconds (1.423x).
Larger single-screen absolute gaps exist at Ranks 40 and 38, but the project
owner's declared iteration order remains Rank 4 first because it permits fast
exact-state iteration, then Rank 32.  No timing repair will be accepted from
one screen: decision-grade claims require three paired waves and less than 2\%
within-arm spread.

The strict Rank-10 margin is narrow even though it is a real cgroup pass.
Future changes must continue to treat memory as an independent acceptance
dimension.  The residual general import/order structures may be revisited only
with a source-backed equal-semantics alternative; they are not silently waived.
