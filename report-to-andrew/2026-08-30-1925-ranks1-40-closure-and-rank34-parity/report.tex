\section{Executive outcome}

The current homogeneous Rank 1--40 candidate solves every instance with the
expected verdict.  All 22 SAT models and all 18 UNSAT proofs have now passed
independent validation, and all 40 result records report certificate and
derived-artifact cleanup with no residue.  Campaign 1657091 therefore closes
the missing-verdict objective on this evaluation set.

The candidate takes 9,305.953 seconds, versus 9,987.021 seconds for its
immediate predecessor, 11,222.888 seconds for frozen accepted Tactix, and

included in these aggregate numbers.

\section{Major progress since the 27 August report}

\subsection{Uniform strategy and ordering contract}

Production now uses Kissat creation order unconditionally.  CaDiCaL arena
order remains available only through the explicit diagnostic arm
\code{TACTIX\_ARENA\_ORDER=1}.  Formula-dependent production profiles and
overrides remain removed.  BVE, Factor, forward subsumption, and Vivify are
uniformly enabled at 100, 50, 100, and 100 permille.  No retained repair uses a
formula, size, density, benchmark, identity, rank, classification, admission,
or effort gate.  This preserves N1--N4 and makes regressions evidence of a
general missing mechanism rather than grounds for restoring a selector.

\subsection{General mechanism closures}

The most consequential retained repairs are:

\begin{itemize}
\item Stable Reorder ties use permanent first-import rank, and scanning stops
  at the 100th open clause literal, matching Kissat's compact order.
\item Packed large on-the-fly strengthening now separates physical
  reconstruction from semantic added/removed notifications.  This closes
  Rank 15 without changing admission or effort.
\item Duplicate AND/OR gate membership, physical large gate bases, and
  general-definition import now follow Kissat's physical clause image.
\item Compact random-decision slots use first-import order filtered to the
  activated live population, while queue and score initialization retain
  activation order.  This removes Rank 20's first search divergence.
\item Strengthen's local mixed stream and proofless/DRAT binary-id storage were
  reduced without changing clause order or the checked search trajectory,
  materially lowering Rank-6 memory and runtime.
\end{itemize}

\section{Rank-34 causal progress}

Rank 34 is the largest remaining absolute SAT gap.  The investigation began at
the first search split and moved upstream through Substitute and Sweep to a
Congruence closure defect.  Tactix registered only currently canonical gate
images, so a residual valued gate could disappear from the rescheduling graph.
Kissat registers every gate's immutable right-hand side and moves occurrence
rings when representatives merge.  The general repair restores Kissat's 3,778
merges and 33 total startup units, including the causal units \code{-1136} and
\code{-574}.  It is retained even though the first full Rank-34 solve regressed
to 744.945 seconds, because it repairs a reference invariant rather than a
benchmark-specific choice.

The next owner is BVE.  Several general physical-lifecycle mismatches have been
closed:

\begin{itemize}
\item syntactic gate implication indices contain only physical binaries;
\item failed candidates compact inspected physical occurrence stacks;
\item an absent heap item receives a score update without reinsertion;
\item newly produced root units flush their connected satisfied clauses at the
  same point as Kissat; and
\item BVE's embedded Kitten consumes the initialization seed before its first
  cleared environment, while Sweep continues to use its fresh seed zero.
\end{itemize}

After these repairs, every one of the first BVE schedule's 14,582 heap pops is
identical to Kissat.  Both solvers then create the same 249-variable second

\section{Risks and decisions}

\begin{itemize}
\item Overall performance is still 1.212466x Kissat, above the 1.10 Phase-4.25
  target.  UNSAT ranks 22, 31, and 38 remain roughly 2.2x/2.2x/2.1x Kissat.
\item Representation and memory remain substantially higher on several large
  SAT instances; complete coverage does not close the memory dimension.
\item The general Congruence repair and newer BVE repairs are intentionally
  retained through downstream regressions.  Reverting them would restore an
  incorrect mechanism and hide the next discrepancy.
\item No broad campaign will be started merely because a bounded trace moved
  forward.  The next production gate is a full Release suite followed by one
  Rank-34 model-checked timing run.
\item The worktree remains uncommitted.  Commit and push follow a coherent,
  cumulatively validated increment, not an intermediate observer result.
\end{itemize}
