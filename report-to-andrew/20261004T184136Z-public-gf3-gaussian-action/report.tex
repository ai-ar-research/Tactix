\section*{Why the action is one complete batch}

Gaussian elimination may derive several root units from the same authenticated
closure. Applying one unit closes the action's assignment-free boundary, so a
per-unit public action could make the remaining simultaneous deductions
unreachable. Discovery therefore offers exactly one deterministic
\code{g3b1:} identity for the complete closure.

That identity commits every supported unit or conflict, the complete
\code{Source}/\code{Scale}/\code{Add} derivation, authentication references,
and exact source clauses. Apply recaptures the live formula, rebuilds the
algebraic and Boolean certificate, exact-matches the identity, and atomically
publishes the whole batch. This preserves a controller-visible choice without
hiding which subset the frontend selected.

\section*{Safety, proof, and accounting}

Corrupt, stale, cross-kernel, interrupted, exhausted, or unsupported-proof
requests decline before solver, proof, journal, or session mutation. One
Kernel-bound session retains durable duplicate keys. Identity construction and
total retained session identity bytes have separate limits and raw counters,
avoiding an unmetered replay payload.

Only entailed unit clauses or the empty clause enter search. Intermediate
case-split clauses remain proof-only. The rule adds no search auxiliary, RAT
definition, PB step, or reconstruction entry. DSR, DRAT, and no-proof are
supported; LRAT and PBP decline before mutation. Nonunit reduced rows remain
outside this first public action.

The action journal records typed limits, exact premises, authenticated
equations, reduced rows, original-source combinations, proof events, installed
clauses, and action identities. Feedback separately records capture, bridge,
certificate, validation, revalidation, proof, journal, identity, session,
unit/conflict, and terminal-status measurements. Fuzz reach is keyed to the
\code{gf3-gauss} attempt counter, which moves only when an exact batch enters
the shared executor.

consumed. The new X14 boundary has not yet been measured on those rows.

fuzz must require X14 reach. Independent proof/model checking, the 1,800-second
