\section*{Evidence and interpretation}
The maintained Tactix retained-tail fixture asserts that the old pure seed is
filtered, a separate fresh eligible seed is not admitted in that call, and
the completed counter advances once. It passed on current Release and
ASan+UBSan binaries. Both pinned references have explicit incomplete flags;
their schedule phase recognizes the old pass as complete and their unschedule
phase recognizes the new empty pass as complete. This is source inference,
not an instrumented reference measurement.

At initial count zero, their next default Sweep call would have limits of
1,024 environment variables and 4,096 clauses, while Tactix would have 512
and 2,048; all three use depth 3 because that cap has already saturated.
We have not measured how often this state occurs or whether the faster ramp
helps. Copying it now could shift proof-producing environments and cumulative
performance. The ledger therefore remains open, not ``parity achieved.''
Documentation option coverage, citations, section references, size, proof-rule
sync and rule/policy boundaries all pass.
