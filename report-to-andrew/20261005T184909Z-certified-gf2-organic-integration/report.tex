\section*{Soundness, scheduling, and learning readiness}

The design keeps the organic-integration boundary: GF(2) reasoning authenticates
theory structure and offers a typed Boolean consequence or conservative
extension to continuing CDCL.  It is neither a private local solver nor a
sequential portfolio stage.  DSR remains the default proof format.

For N1, the affine row is an ordinary public action with an exact payload; the
search configuration, propagation, and semantic advice are explicit choices
on the shared controller path.  For N2, target credit requires an independently
checked reconstructed model or machine-checkable proof, including introduced
variable projection and exact provenance.  For N3, the accepted default
baseline is competitive, but the post-fix source must repeat all four gates.
For N4, search configuration, action ordering, effort, retry status, and advice
are typed and observable; the scheduling-parity ledger and final policy
acceptance remain pending.

This also preserves the learning preparation.  Default, random, and future
learned policies share the same action identities and execution path; pure
observations and after-action raw feedback expose effort and result without
rollback or hidden fallback.  The immediate sequence is to finish lossless
telemetry, freeze and validate the corrected four-row campaign, require checked
target outcomes, then run effective both-policy fuzz plus fresh Debug and all
four regression gates.  Only coherent checked evidence should justify
expansion to ranks 540, 896, 1004, and MAB-only 557.  The saved
\code{d170b4a5} comparison remains authoritative and is not rerun.
