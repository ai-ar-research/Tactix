\section*{Outcome}
The outstanding native-DSR H2 checker rejection now has a substantially
smaller, pinned reproducer: 16 original-CNF clauses and a 314-byte proof,
down from 42 clauses and 680 bytes. The same public-API action program still
returns UNSAT. A clause-deletion shrink preserved the exact checker-contract
split across 88 candidate tests in hwulab SLURM job \texttt{1723448}, which
completed successfully in three seconds. The final case is one-clause-
deletion minimal under this specific oracle, not a general minimal proof.
Full hashes, commands, logs, and artifacts are in
\href{../../benchmarks/reports/2026-09-25-am436-h2-one-reason-shrink.md}{AM436}.

\section*{Certificate evidence}
The frozen canonical no-option \texttt{dsr-trim} rejects the reduced proof
in backward mode at addition line 21 (a watch-pointer error) and in forward
mode at line 12 (no UP contradiction for RAT clause 15). Its verbose backward
trace identifies just one ignored deletion: input clause 15, \texttt{-18 19},
is retained as an implied-unit reason. With the diagnostic
\texttt{--delete-implied-units} option, both backward and forward elaborations
return \texttt{s VERIFIED UNSAT}; pinned Trestle independently verifies each
decoded LSR against the same original CNF. This isolates the proof-state
boundary but does \emph{not} justify changing the production checker option.

A negative control retaining only the first proof line returns exit code zero
with \texttt{s VALID}, not \texttt{s VERIFIED UNSAT}. It confirms that the
checker status, not process exit code alone, must be the acceptance test.
The current production oracle already enforces that distinction.
