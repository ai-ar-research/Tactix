\section*{Executive summary}
Matched current-Tactix/current-Kissat Substitute localization assigned the
first portable same-work cost gap to reconstructing permanent first-import
order through the external-variable map on every hot comparison.  The accepted
repair preserves that permanent external rank as proof and reconstruction
authority while maintaining an equivalent direct image over current compact
Kernel identities.  First import writes both views, variable compaction remaps
the direct view, and invariants assert equality.  The fallback for unrecorded
public-API variables remains stable external order.

\section{Localization, rejected arm, and source boundary}
Matched Substitute campaign \code{1647662} compares completed invocations from
the same conflict-9450 state.  Tactix spends 1766 ms in Substitute versus
931.761 ms in current instrumented Kissat.  SCC discovery is not the owner:
601 ms versus 570.808 ms.  Tactix's rewrite and maintenance tail costs 1159 ms
versus about 361 ms; its measured substages include 221 ms snapshot, 265 ms
binary rewrite, 190 ms large rewrite, 34 ms post-work, and 419 ms collection.
Source and sampled-cycle tracing identify repeated
\code{kernel_import_var_order} translation as the earliest bounded
representation owner.

The first prototype built a local per-call order vector.  Exact stage
\code{1647664} preserved SHA-256
\hashcode{3b87bb36da711bcef3ca877f3922e9fa5f8a3c6ae9d638c1ae18d4965bd92c5f}
and halved helper cycles, but full Rank-27 pair \code{1647680} regressed
453.199 to 461.583 seconds and raised memory.  That arm is rejected.

The accepted general repair adds one 32-bit rank per current Kernel variable.
The external-rank vector remains permanent and its import-order vector remains
the inverse.  The new direct internal-rank image is initialized to
\code{UINT32_MAX}, written with
the same rank at first import, and compacted alongside every other per-current-
variable vector.  Hot current-variable comparisons read it directly.  Only an
unrecorded direct Kernel client takes the unchanged external-order fallback.
The invariant checker compares both views after every remap, and the Kernel
regression pins the direct image before and after a compaction with holes.
There is no change to candidate order, proof order, ticks, scheduling, learning,
pruning, reconstruction identity, N1--N4, or the proof-rule/strategy boundary.

\section{Disposition and next work}
Claude's PASS closes the final correctness gate.  The evidence supports the
maintained direct import-rank image
as a portable Kernel representation repair rather than a benchmark arm.  The
300-second Rank-27 target remains a milestone, not a stopping rule.

The next ordered increment is collection and rewatching.  Freeze this accepted
baseline and current-Kissat comparator, then trace watch compaction, reference
forwarding, metadata reconstruction, sparse collection, and rewatching with
work normalized by entries and literals.  The first bounded hypothesis is a
fused compact-and-forward traversal, gated first by exact common-prefix order,
ticks, scheduling, learning, and pruning, then full Rank 27 and mechanism-
relevant B+C, then the complete B28+C5 gate, independent proof/model checks,
Claude-owned fuzz, and a separate report/commit.  Substitute's remaining
rewrite/collection cost follows that work; residual Congruence and broad search
quality remain queued behind it.
