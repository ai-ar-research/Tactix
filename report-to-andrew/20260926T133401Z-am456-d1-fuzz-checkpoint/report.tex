\paragraph{New N2 failure.}
Opus retained a 29-variable, 27-clause public Probe--CCE--solve reproducer.
The same UNSAT program emits byte-identical native DSR on current and parent
sources, and pinned no-option dsr-trim rejects it in both backward and forward
modes. Explicit LRAT and DRAT from the same program independently verify.
The DSR stream emits a Probe unit, ten deferred support deletions, later root
units, then a witnessed auxiliary addition. The checker's diagnostic state
has root \texttt{21} and \texttt{-30} when checking \texttt{30 -21}; the
auxiliary transaction is rejected. This points to a DSR proof-order and
root-closure mismatch. The cause and general repair still require proof, and
the canonical checker contract is unchanged.
