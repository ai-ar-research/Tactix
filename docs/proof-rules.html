M1

Propagate

Run Boolean constraint propagation to conflict or fixpoint

public
F not refuted ∧ no unresolved conflict ∧ τ not at BCP fixpoint ────────────────────────────────────────────────────────────── M1 ⟨F,R,τ,ρ,π⟩ → ⟨F,R,τ·forced,ρ,π·δ⟩

Effect

Assign every forced literal at its true level. Stop at the first conflict or at fixpoint; a root conflict returns Unsat.

Proof δ & soundness

add_derived_unit records root units with LRAT hints or as explicit witnessless DSR RUP additions; DRAT leaves ordinary propagated units implicit. add_empty records a root conflict. BCP assigns only consequences of F ∧ M.

Follow implications until nothing else is forced. If a clause has one possible literal left, that literal must be true. If every literal in a clause becomes false, propagation has found a conflict.

A root implication

F = {(a), (¬a ∨ b)} τ = [] ⇒ τ′ = [a@0, b@0]

The unit a forces b. LRAT and DSR record both derived root units so later proof rules see the same root formula.

A root contradiction

F = {(a), (¬a)} ⇒ a@0 and ¬a@0 ⇒ ∅, Unsat

The empty clause is RUP from the contradictory units.

M2

Decide

Choose any unassigned literal and open a search branch

public
x unassigned ∧ no unresolved conflict ∧ F not refuted ────────────────────────────────────────────────────── M2(l) dl := dl+1 ; τ := τ · (l@dl, reason=DECISION) δ = ε

Instance

Any unassigned literal and phase. No propagation-fixpoint requirement exists in the abstract calculus.

Soundness

A decision is a case split, not a logical inference; it changes only the explored branch.

Make a reversible guess. Decide does not claim the literal follows from the formula, so it emits no proof line. A later conflict can undo the branch.

Positive phase

F = {(a ∨ b)}, τ = [] Decide(a) ⇒ τ′ = [a@1(decision)]

The clause is satisfied on this branch; no proof delta is emitted.

Choose the other phase

F = {(a ∨ b)}, τ = [] Decide(¬a) ⇒ τ′ = [¬a@1] M1 then forces b@1

N1 exposes both a and ¬a as legal instances.

M3

ConflictAnalysis

Learn a 1-UIP clause and backjump atomically

public
Γ = F ∪ R; K₀ = Cκ; d = max level in K₀ Kᵢ₊₁ := Res(Kᵢ, reason(qᵢ), var(qᵢ)) where qᵢ is the latest trail assignment at level d and Kᵢ contains more than one level-d literal stop with Kₘ = {¬u} ∪ B (u is the first UIP) L := minimize/shrink(Kₘ) = {¬u} ∪ B′ j := max({level(l) | l ∈ B′} ∪ {0}) conflict Cκ recorded ∧ Γ not refuted ∧ d>0 ∧ t ∈ [j,d−1] ────────────────────────────────────────────────── M3(t) ⟨F,R,τ,ρ,π⟩ → ⟨F,R∪{L},prefixₜ(τ)·[¬u@j←L],ρ,π·δ⟩

Certificate, in emission order

δ = ∏(C↦C′)∈OTFS[add_rup(C′,hC′) · del(C)] · add_rup(L,hL) · ∏D∈eager(L)del(D). Here hL lists the reason clauses used by analysis/minimization in increasing trail order, then the conflict clause. The backtrack and assertion emit nothing. For root refutation, LRAT emits add_rup(∅,h⊥); DRAT emits its empty-clause line.

Effect

The canonical target is t=j, and ¬u@j←L means “assign ¬u at true level j with reason L.” A chronological target may retain levels above j. OTFS replacements stay in their parent clause’s irredundancy partition.

Soundness

Every resolution step preserves entailment. Negating L replays hL to the recorded conflict, so L is RUP. After truncation, every literal in B′ is false and L forces ¬u.

Walk backward from the conflict through the reasons for the latest assignments. Stop when only one literal from the conflict level remains: that assignment is the first UIP. Negating it, together with the lower-level literals encountered along the way, forms the learned clause. Its highest lower level is exactly where the clause becomes unit, so the solver backtracks there and propagates the negated UIP.

A genuine non-chronological jump

C₁=(¬b∨c), C₂=(¬b∨d), C₃=(¬c∨¬d∨¬a) trail: a@1(decide), b@2(decide), c@2(C₁), d@2(C₂) C₃ is false Res(C₃,C₂,d) = (¬c∨¬a∨¬b) Res(·,C₁,c) = L=(¬a∨¬b) d=2, u=b, j=level(¬a)=1 backtrack(1); assert ¬b@1 with reason L hL=[C₁,C₂,C₃]

Under assumptions a∧b, the LRAT hint order first propagates c, then d, then reaches C₃. Thus L is RUP and becomes unit at level 1.

Root refutation

C₁=(p), C₂=(¬p∨q), C₃=(¬p∨¬q) trail: p@0(C₁), q@0(C₂) C₃ is false at level 0 d=0 ⇒ no backtrack target and no UIP assertion LRAT: add_rup(∅,[C₁,C₂,C₃]) DRAT: add_empty(∅) result: Unsat

At root there is no decision to revise. The transition certifies the empty clause directly and marks the formula inconsistent.

M4

Backjump

The folded tail of M3, not a separately schedulable rule

folded
M3 has learned asserting clause L with jump level j ──────────────────────────────────────────────────── M4 (inside M3) truncate τ to target t ∈ [j, level−1]; assert UIP at true level j δ = ε

Status

No public guard, instances, or apply surface. The target is an M3 instance parameter.

Soundness

Removing trail assignments is safe; the learned clause forces its UIP at j even if chronological backtracking retains higher decisions.

Undo only as much search as the learned clause requires. Tactix exposes this choice through ConflictAnalysis rather than allowing a half-finished learned clause to escape between two rules.

Canonical non-chronological jump

current level = 5 learned L has second-highest level j = 2 target t = 2 ⇒ remove levels 3..5; assert UIP

The clause becomes unit exactly at its standard jump level.

Chronological target

current level = 5, j = 2 choose target t = 4 ⇒ retain levels 3..4 assert UIP with true level 2

The extra decisions remain, but the assertion keeps the logical level determined by its reason.

S1

Restart

Discard a trail suffix while keeping learned knowledge

public
F consistent and not refuted ────────────────────────────── S1(k) ⟨F,R,τ,ρ,π⟩ → ⟨F,R,prefixₖ(τ),ρ,π⟩ δ = ε if prefix₀(τ) still falsifies a recorded conflict: Refuted, δ = add_empty

Effect

Drop to a chosen keep level; clauses stay unchanged. Clear a stale conflict, retain a non-root conflict, or prove a surviving root conflict.

Soundness

Removing temporary assumptions cannot remove or create formula models; a conflict supported entirely by proved root assignments refutes the formula.

Start searching from a shallower point without forgetting learned clauses. Restarts change the route through the search tree. If the root facts alone still falsify a recorded clause, the solver emits the empty-clause proof and stops.

Full restart

τ = [u@0, a@1, b@2, c@3] Restart(0) ⇒ τ′ = [u@0]

Only root facts survive.

Prefix restart

τ = [u@0, a@1, b@2, c@3] Restart(1) ⇒ τ′ = [u@0, a@1]

A partial restart keeps the first decision branch.

S2

Reduce

Forget selected redundant learned clauses

public
F not refuted ∧ D ⊆ R ∧ no d ∈ D is reason-locked ────────────────────────────────────────────────── S2(D) R := R \ D ; δ = ∏ d∈D del(d)

Effect

Delete selected learned clauses, compact storage, forward surviving reasons, and retire deleted root reasons to proved units. Optional root compaction also shortens root-false clauses and deletes root-satisfied clauses with the corresponding proof operations; report effective changes even with zero learned victims.

Soundness

Every deleted clause is redundant/entailed; proof checkers accept deletions without a chain. Non-root and pending learned-clause reasons stay locked; proved root units need no clause lock.

Throw away learned hints that are no longer worth their memory cost. Root assignments may simplify original clauses during compact collection; non-root and pending reasons are protected. A proved root assignment can survive without its old clause.

Forget a weak learned clause

R = {(a ∨ b), (c ∨ d ∨ e)} D = {(c ∨ d ∨ e)} ⇒ R′ = {(a ∨ b)} δ = del(c ∨ d ∨ e)

The solver may need to rediscover it later, but satisfiability is unchanged.

Protect a non-root reason

level(x) > 0 ∧ reason(x) = (x ∨ ¬a) candidate D contains reason(x) ⇒ skip that clause

Deleting it would leave the current trail with a dangling explanation.

S5

Lucky

Search configured complete assignments and report SAT only on success

public
F consistent and not refuted; level(τ)=0; no pending conflict ──────────────────────────────────────── S5 configured complete-assignment candidate A if A ⊨ every live clause: Sat(A) ; otherwise restore root σ exactly δown = ε

Effect

Every stable ID 0–24 is active: probes 0–5; SAT constructors 6–14, 17, 18 and 21; structural refutations 15/16; startup refutations 19/20/22; and proof-only XOR/exact-one refutations 23/24. Canonical Lucky is the ordered 0–5 probe cascade.

Soundness

Every completed constructor candidate requires a whole-live-CNF model check. Incomplete 6–10/21 candidates are heuristic guidance and prove nothing; 6/7 cannot refute. Structural UNSAT results require exact recognition, bounded proof preflight and a checked empty-clause derivation; unsupported formats and incomplete work decline before mutation.

Try the reference assignments, a bounded SAT constructor, or a certified structural refutation. Constructors keep their historical identities; incomplete supported searches may guide later phases, while parity and exact-one refutation remain separate actions 23/24.

A lucky model

F = {(a ∨ b), (¬a ∨ b), (a ∨ ¬b)} try A = {a=true, b=true} A ⊨ F ⇒ Sat

All three clauses are satisfied.

A failed attempt

F = {(a ∨ b), (¬a ∨ b)} try A = {a=true, b=false} conflict ⇒ restore σ

The rule does not learn from its own failed guess; ordinary search continues from the original state.

C1

SubsumeForward

Delete a clause covered by a stronger live clause

public
d,c ∈ F live ∧ d ⊆ c ──────────────────────── C1(d,c) F := F \ {c} ; δ = del(c)

Precondition

The subsumer d is irredundant/live. The victim need not be restricted for soundness.

Soundness

d ⊨ c, so keeping both imposes exactly the same models as keeping only d.

A shorter clause makes a longer superset useless. Any assignment satisfying the shorter clause already satisfies the longer one.

Direct subset

d = (a ∨ b) c = (a ∨ b ∨ c) d ⊆ c ⇒ delete c

The literal c adds no constraint.

Binary subsumer

d = (¬x ∨ y) c = (¬x ∨ y ∨ z ∨ w) ⇒ del(c)

Binary clauses have an irredundant lifecycle in this calculus.

C2

Strengthen

Remove a literal by self-subsuming resolution

public
c = (x ∨ A), d = (¬x ∨ B), c′ = A ∪ B, c′ ⊂ c ───────────────────────────────────────────────────── C2 F := (F ∪ {c′}) \ {c} δ = add_rup(c′,[c,d]) · del(c)

Effect

Add the smaller resolvent before deleting its parent. Unit and empty results assert or refute.

Soundness

The resolvent is RUP from its two parents; add-before-delete preserves proof availability.

Use another clause to prove one literal in a clause is unnecessary. The replacement is strictly stronger and checker-verifiable.

Drop a pivot literal

c = (x ∨ a ∨ b) d = (¬x ∨ a) resolve x ⇒ c′ = (a ∨ b) add c′; delete c

The resolvent is a strict subset of c.

Collapse to a unit

c = (x ∨ a) d = (¬x) resolve x ⇒ c′ = (a) ⇒ assert a@0

A strengthening can expose a new root fact.

C3

Vivify

Distill a clause through speculative propagation

public
Γ=F∪R; C∈Γ; P=(p₀,…,pₘ₋₁)=C after root-false stripping Aᵢ={¬p₀,…,¬pᵢ}; propagation proves a strict C′⊂C ──────────────────────────────────────────────────────────── C3(C) Γ′ := (Γ∪{C′})\{C}; C′ stays in C's irredundancy partition

Four concrete distillation outcomes

Γ∧Aᵢ⊢₁⊥ ⇒ C′={p₀,…,pᵢ}. If the prefix before pᵢ implies pᵢ, use the same prefix plus pᵢ. If it implies ¬pᵢ, use C′=P\{pᵢ}. If propagation under Aᵢ implies a later clause literal q, use C′={p₀,…,pᵢ,q}.

Certificate order

Emit add_rup(C′,h)·del(C). The hint list contains used root-unit/reason ids in increasing trail order. A probe conflict appends its conflict id. An implied-negation rewrite appends C.id after the reasons force ¬pᵢ. For implied literals, their own final reason closes the chain, so C is not cited afterward.

Boundary outcomes

A root-satisfied candidate contributes only del(C). A unit C′ is asserted at root; an empty C′ emits the refutation. Root-false stripping alone is not a rewrite—it only changes the probe list.

Falsify an ordered prefix of the clause and let propagation show how much of the clause is really needed. A conflict proves the prefix itself is a clause; an implied clause literal can close an even shorter clause. Every successful result is independently RUP before the original is deleted.

Conflict after a strict prefix

C=(a∨b∨c) A=(a∨d), B=(b∨¬d) assume ¬a ⇒ A forces d assume ¬b ⇒ B conflicts C′=(a∨b), h=[A,B] add_rup(C′,[A,B]); del(C)

The conflict is reached before c is assumed, so c is absent from the replacement.

Implied negation removes one literal

C=(a∨b∨c), E=(a∨¬b) assume ¬a ⇒ E forces ¬b C′=(a∨c) under ¬C′: E forces ¬b; C is then false h=[E,C] add_rup(C′,[E,C]); del(C)

Here the candidate itself is the final conflicting hint. This is why its id belongs last rather than in every Vivify chain.

V1

Probe

Derive root units by refuting an assumed literal

public
p unassigned ∧ F ∧ M ∧ p ⊢₁ ∅ ─────────────────────────────── V1(p) F := F ∪ {(¬p)} ; δ = add_rup((¬p), conflict-chain)

Effect

Test candidates with full propagation, collect each failed literal’s negation, then assert the batch at root.

Soundness

If assuming p unit-propagates to conflict, F ∧ M ⊨ ¬p.

Temporarily try a literal. If propagation immediately proves that choice impossible, its opposite is a permanent fact.

Two opposing implications

(¬p ∨ q), (¬p ∨ ¬q) assume p ⇒ q and ¬q ⇒ add (¬p)

The failed assumption becomes a root unit.

Conflict through a long clause

(¬p ∨ a ∨ b), (¬a), (¬b) assume p ⇒ clause becomes empty ⇒ add (¬p)

Full Probe sees non-binary clauses, unlike V2.

V2

Backbone

Run failed-literal probing using only the binary graph

public
p unassigned ∧ BIG(F) ∧ p ⊢₁ ∅ ──────────────────────────────── V2(p) F := F ∪ {(¬p)} ; δ = add_rup((¬p), binary-chain)

Scope

Identical inference to V1, restricted to permanent binary implications.

Soundness

A binary reason chain is a special case of full unit propagation, so V2’s conclusions are a subset of V1’s.

A cheaper Probe. Follow only two-literal clauses. It finds fewer failed literals but traverses a much simpler graph.

Depth-one failure

(¬p ∨ q), (¬p ∨ ¬q) p ⇒ q and ¬q ⇒ add (¬p)

Both implications are binary edges.

Failure along paths

p→q, q→r, p→s, s→¬r assume p ⇒ r and ¬r ⇒ add (¬p)

The proof chain is the four binary clauses on the two paths.

V3

Substitute

Collapse equivalent literals found as BIG strongly connected components

public
Γ = F ∪ R; S is a non-trivial SCC of BIG(Γ) μ(l) := representative of l in S λₗ := (¬l ∨ μ(l)) [transient bridge] C^μ := unique({μ(l) | l∈C}), after root-false stripping S contains no pair x,¬x ──────────────────────────────────────────────────────── V3(S) Γ′ := (Γ \ touched(S)) ∪ {C^μ | C touched, C^μ active/non-tautological} ρ′ := ρ · ∏ₓ [({¬x,μ(x)}, witness ¬x), ({x,¬μ(x)}, witness x)]

Certificate, in emission order

δbridge = ∏l rewritten add_rup(λl,path(l,μ(l))). For a touched clause C, a satisfied or tautological C^μ contributes only del(C); otherwise it contributes add_rup(C^μ,[deduplicated bridge/root-unit ids in proof-id order,C.id]) · del(C). After every rewrite, delete all λl. Each replacement is add-before-delete; witness pushes emit no proof line.

Contradictory SCC

If x and ¬x share an SCC, emit add_rup({¬x},path(x,¬x)) · add_rup({x},path(¬x,x)) · add_empty([id¬x,idx]). No rewrite or witness follows.

Soundness and model

A forward BIG path proves every bridge. The symmetric witness pair recovers x=μ(x) during the reverse walk regardless of the retired variable’s temporary search value.

Prove a replacement name in both directions, rewrite every occurrence, then remember how to undo the renaming. The temporary bridge clauses make each rewritten clause independently checker-verifiable. The two reconstruction entries ensure the eliminated variable is restored to the representative’s value.

One concrete clause rewrite

C₁=(¬x∨y), C₂=(x∨¬y) [x↔y] C₃=(x∨z), μ(x)=y λₓ=(¬x∨y), hλ=[C₁] C₃^μ=(y∨z), h₃=[id(λₓ),C₃] add_rup(C₃^μ,h₃); del(C₃) ρ += ({¬x,y}, witness ¬x) · ({x,¬y}, witness x)

The equivalence clauses themselves rewrite to tautologies and are deleted. The displayed bridge certifies the nontrivial rewrite of C₃.

Contradictory SCC

x→y→¬x path ids [C₁,C₂] ¬x→z→x path ids [C₃,C₄] add_rup((¬x),[C₁,C₂]) id U¬ add_rup((x), [C₃,C₄]) id U+ add_empty([U¬,U+]) result: Unsat

A literal equivalent to its own negation yields two opposing RUP units and then the empty clause.

V4

TransitiveReduce

Delete a binary implication duplicated by another path

public
e = (¬p ∨ r) ∈ F ∧ path p ⟹ r exists in BIG(F)\{e} ────────────────────────────────────────────────────── V4(e) F := F \ {e} ; δ = del(e)

Effect

Delete redundant edges using round-local tombstones so no deletion relies on another edge being deleted in the same round.

Soundness

The surviving path resolves to the removed binary, so the remaining formula entails it.

Remove shortcut edges when a surviving route says the same thing. Reachability stays the same, but the binary graph becomes smaller.

Triangle shortcut

(¬p ∨ q), (¬q ∨ r), (¬p ∨ r) p→q→r duplicates p→r ⇒ delete (¬p ∨ r)

The first two binaries resolve to the third.

Longer alternate path

p→q, q→s, s→t, p→t ⇒ delete direct p→t

The path remains live throughout the round.

V5

Sweep

Discover literal equivalences with a local SAT environment

public
Eₖ := Cₖ \ Zₖ, where every z∈Zₖ is root-false with unit id U_z Env := {Eₖ}; F ⊨ Eₖ via [U_z…, Cₖ.id] B→ := (¬a∨b); B← := (a∨¬b) Env ∧ a ∧ ¬b ⊢ ∅ and Env ∧ ¬a ∧ b ⊢ ∅ both directions validated over the main proof before either is written ────────────────────────────────────────────────────────────── V5(a,b) F′ := F ∪ {B→,B←}; R,τ,ρ unchanged

RUP replay path

Negate B→ in the main kernel, propagate to conflict, and record its reasons in propagation order followed by the conflict as h→; repeat for B←. Then emit add_rup(B→,h→) · add_rup(B←,h←).

General derivation path

For a captured sub-solver derivation D₁,…,Dₘ=B, emit each add_rup(Dᵢ,[strip-unit ids first, translated antecedent ids]) in order. Validate both complete direction sequences without mutation first; if either cannot be translated exactly, emit neither.

Why the environment alone is insufficient

The checker sees the main proof database, not Env. Environment entailment makes discovery sound, but replay or translated derivations make the additions checkable. Final units and binaries stay live; translated support clauses are transient and are deleted newest first. Before native DSR deletes them, a proof-only watched-UP closure publishes a unit exactly when its propagation reason is a retiring support clause, preventing a deleted reason from retracting checker state without prematurely strengthening later RAT obligations. No reconstruction witness is needed.

Ask a small local SAT solver whether two literals can ever differ. If both disagreement cases are impossible—and the main checker can replay them—the equivalence is added.

Two exact RUP directions

C₁=(¬a∨c), C₂=(a∨¬c) C₃=(¬c∨b), C₄=(c∨¬b) B→=(¬a∨b): assume a,¬b C₁ forces c; C₃ conflicts h→=[C₁,C₃] B←=(a∨¬b): assume ¬a,b C₄ forces c; C₂ conflicts h←=[C₄,C₂] δ=add_rup(B→,h→)·add_rup(B←,h←)

The local solver discovers a↔b; the two main-kernel replays independently certify it.

Root-false stripping has provenance

U=(¬r) [root unit] C=(r∨¬a∨b) E=C\{r}=(¬a∨b) environment provenance for E: [U,C] sub-solver antecedent C maps to [U,C] before its translated RUP step is emitted

Without stripping r, the sub-solver could satisfy C using a literal that the main root assignment already makes false.

V6

Congruence

Equate outputs of structurally identical AND, XOR, and ITE gates

public
Gₐ and G_b are complete gates of the same kind canon(Gₐ) = canon(G_b) = (kind,key); outputs a,b B→ := (¬a∨b); B← := (a∨¬b) ────────────────────────────────────────────────── V6(Gₐ,G_b) F′ := F ∪ {B→,B←}; unite(a,b); ρ unchanged requeue every gate whose canonical input class changed

Common certificate order

Emit a gate-kind-specific transient family T; emit add_rup(B→,h→) · add_rup(B←,h←); then delete T newest first. Both final directions are justified before either is added. A failed or tautological replay declines the merge instead of emitting an unchecked line.

AND

No ladder is needed. For B→, cite Gₐ’s input binaries, any BIG bridge paths between corresponding representative inputs, then G_b’s base clause. Reverse the gates for B←.

ITE

With shared condition c, emit four replay-RUP ternaries: B→∨c, B→∨¬c, B←∨c, B←∨¬c. Each final binary cites its two condition cases; then the four ternaries are deleted.

XOR and degeneracy ladders

For normalized shared inputs r₁…r_k, let rᵢ⁰=rᵢ and rᵢ¹=¬rᵢ. For each direction B, emit Λs,ε={r₁ε₁,…,r_sε_s}∪B for s=k−1,…,1 and every ε∈{0,1}s. Top rungs replay over the gates; each lower rung cites its two opposite-sign parents; B cites the two s=1 parents. For k≤1, replay B directly. A unit or unary-merge degeneracy uses the same ladder over representatives cancelled during canonicalization. An ITE that becomes an AND/OR and then a constant needs both original-condition cases before its output unit; the effective AND name alone does not make that unit RUP. A root-valued ITE-to-AND may use its original clauses reduced by root values instead of publishing duplicate watched implications; typed matching and unit closure still apply.

Recognize duplicate circuit computations. Once two gate outputs are known equal, gates above them may become duplicates too, so the equivalence cascades through circuit layers.

Duplicate AND gates, exact chains

Gₒ: A₀=(o∨¬a∨¬b), A₁=(¬o∨a), A₂=(¬o∨b) Gₚ: P₀=(p∨¬a∨¬b), P₁=(¬p∨a), P₂=(¬p∨b) B→=(¬o∨p), h→=[A₁,A₂,P₀] assume o,¬p ⇒ A₁:A₂ force a,b ⇒ P₀ conflicts B←=(o∨¬p), h←=[P₁,P₂,A₀] add_rup(B→,h→); add_rup(B←,h←); unite(o,p)

Input sorting identifies the gates; each output implication has a three-clause RUP certificate.

Degeneracy after an earlier merge

Gₒ encodes o=a∧b closure already proved b↔¬a canon(Gₒ)=o=a∧¬a=0 assume o (¬o∨a) forces a (¬o∨b) forces b; bridge b→¬a forces ¬a conflict ⇒ add_rup((¬o), replay chain)

The original gate is complete and nondegenerate; it becomes constant only after congruence closure identifies an input with the complement of another.

V6a

Binary-resolution unit channel

A second inference performed inside V6

internal
(l ∨ o) ∈ F ∧ (l ∨ ¬o) ∈ F ───────────────────────────────── V6a (inside V6) F := F ∪ {(l)} δ = add_rup((l), replayed binary chain)

Effect

Collect derived units with V6’s degeneracy units; contradictory units resolve to empty.

Status & soundness

Not a public rule. Ordinary resolution on o yields (l∨l)=(l).

Whichever value the side literal takes, the other literal must be true. V6 scans binaries for this pattern at linear cost.

Resolve to a unit

(l ∨ o) (l ∨ ¬o) resolve o ⇒ (l) ⇒ assert l@0

The checker chain is obtained by replaying the failed assumption ¬l.

Resolve to contradiction

(l∨o),(l∨¬o) ⇒ (l) (¬l∨p),(¬l∨¬p) ⇒ (¬l) (l),(¬l) ⇒ ∅

Opposite units found in one batch refute the formula.

E1

BVE

Eliminate a variable with bounded Davis–Putnam resolution

public
P={Cᵢ={x}∪Aᵢ}; N={Dⱼ={¬x}∪Bⱼ} Qᵢⱼ := unique(Aᵢ∪Bⱼ), after root-false stripping Q := {Qᵢⱼ | Qᵢⱼ non-tautological and required} |Q| ≤ |P|+|N|+bound ──────────────────────────────────────────────────── E1(x) F′ := (F \ (P∪N)) ∪ Q ρ′ := ρ · ∏ᵢ(Cᵢ,witness x) · ∏ⱼ(Dⱼ,witness ¬x)

Certificate, in emission order

For every Qᵢⱼ, emit add_rup(Qᵢⱼ,[root-unit ids stripped from Cᵢ, root-unit ids stripped from Dⱼ, Cᵢ.id, Dⱼ.id]). Under ¬Qᵢⱼ, Cᵢ forces x and Dⱼ conflicts. Add all resolvents before deleting every pivot clause. Witness pushes emit no line.

Gate reduction

The full cross product is the baseline. A detected gate may omit only antecedent×antecedent pairs justified by the gate-remainder unsatisfiability condition; every resolvent that remains still uses the same two-parent RUP certificate.

Soundness and model

Davis–Putnam elimination is equisatisfiable. During reverse reconstruction, a falsified remainder Aᵢ selects x; a falsified Bⱼ selects ¬x. The resolvents guarantee those demands never conflict.

Remove a variable while preserving every consequence between the clauses on its two polarities. BVE is allowed only when the replacement does not grow too much.

One resolvent and its witnesses

C=(x∨a), D=(¬x∨b) Q=(a∨b) add_rup(Q,[C,D]) ρ += (C,witness x) · (D,witness ¬x) del(C); del(D) model a=0,b=1: C forces x=1 model a=1,b=0: D forces x=0

The resolvent prevents both remainders from being false, so reverse reconstruction can always satisfy both removed clauses.

Tautological pair still needs witnesses

C=(x∨a), D=(¬x∨¬a) Q=(a∨¬a)=⊤ [emit no resolvent] ρ += (C,witness x) · (D,witness ¬x) del(C); del(D) a=0 ⇒ reconstruct x=1 a=1 ⇒ reconstruct x=0

The reduced formula has no clause, but the witness pair recovers x=¬a for the original formula.

Effect

Soundness & model

Fresh-variable additions are RAT; quotient resolvents are the still-live grid. No ρ witness: project the extension variable out.

Name a repeated rectangular pattern with a fresh helper variable. Each remainder Rⱼ may contain several literals; the binary grid is the singleton-remainder case. This is the inverse of eliminating that helper with BVE.

A 2×3 grid

G = {f₁∨r₁,f₁∨r₂,f₁∨r₃, f₂∨r₁,f₂∨r₂,f₂∨r₃} 6 clauses → add: (x∨f₁),(x∨f₂), (¬x∨r₁),(¬x∨r₂),(¬x∨r₃) 5 clauses

Effect

Soundness

Resolve two three-literal clauses when their overlap keeps the result short. The added clause can make later propagation stronger.

The shared b keeps the union at size three.

HyperBinaryRes

Derive a binary from BIG paths that falsify the rest of a clause

public
C=(l₀∨l₁∨…∨lₖ), k≥2 for each i>0: d=qᵢ₀→qᵢ₁→…→qᵢₙᵢ=¬lᵢ in BIG(F) B:=(¬d∨l₀) ──────────────────────────────────────────────────── X6(C,l₀,d) if ¬d∉C: F′=F∪{B} if ¬d∈C: F′=(F∪{B})\{C} [B⊂C]

Certificate, not a placeholder

At the clean root assume d∧¬l₀ and replay ordinary propagation. Let h_B be the binary reason ids actually used, in propagation order, followed by C.id as the conflict. Emit add_rup(B,h_B); emit del(C) exactly in the second state case above. If replay does not conflict, emit nothing.

Dominator

The implementation discovers d as the closest common dominator of the true literals ¬lᵢ in one binary implication tree. This gives a stronger binary than using the original probe root.

Soundness

With d true, the paths falsify every alternative lᵢ; with l₀ also false, C conflicts. Thus B is entailed, and deleting a clause it subsumes preserves all models.

If one condition makes every alternative in a clause false, it must force the remaining literal. Record that fact as a new binary clause.

Derive, but keep the source

C=(u∨a∨b) E₁=(¬d∨¬a), E₂=(¬d∨¬b) B=(¬d∨u) assume d,¬u E₁ forces ¬a; E₂ forces ¬b; C conflicts h_B=[E₁,E₂,C] add_rup(B,h_B); keep C

The new binary is stronger propagation knowledge, but it does not syntactically subsume C.

Derive and subsume

C=(u∨¬d∨b), E=(¬d∨¬b) B=(¬d∨u) assume d,¬u ⇒ E forces ¬b ⇒ C conflicts h_B=[E,C] add_rup(B,h_B); del(C) [B⊂C]

The binary is added first, so the proof and solver retain the subsumer before the longer source disappears.

public

Effect

Add the candidate and perform ordinary root propagation; existing clauses and reconstruction state remain unchanged. A validated root-simplified clause already present is a format-neutral no-op with no proof line.

Certificate

Every root fact consumed by validation is already an explicit DSR unit. Mapping sources are serialized as positive variables with signed images. General witnesses use fresh proof-only z: add (¬z∨C) by RAT, (z∨C) by SR with z true and σ, then C by RUP; delete both temporary nonunit clauses. Soundness

The substitution condition makes C satisfiability-preserving. dsr-trim checks the equivalent DSR encoding and Trestle checks the elaborated LSR.

Producer boundary

ULC-AMO completion, orbitopal detection, graph automorphisms, and Schreier-derived actions only discover candidate tuples (C,p,σ). They do not add guards or create separate calculus rules: every emitted instance remains an ordinary X7 application against the current proof-visible formula.

Use a symmetry or another finite substitution to justify adding a clause that removes equivalent search. The producer discovers candidates; the proof rule accepts every legal explicit tuple.

ULC-AMO completion

R=(r₀∨…∨rₖ), each rᵢ unique in F for every i<j propose Cᵢⱼ=(¬rᵢ∨¬rⱼ) resolve Cᵢⱼ with the only rᵢ-clause R ⇒ the resolvent contains rⱼ∨¬rⱼ

Each missing pairwise exclusion is blocked and therefore has an SR witness. Uniqueness is re-evaluated at the applicable semantic boundary; order, batching, repetition, and work limits belong to the strategy.

Orbitopal fixing

detect an interchangeable row/column matrix exact-check each full signed action against F choose the next prefix clause C and construct (p,σ) validate or structurally certify X7(C,p,σ)

For a generated prefix, action i must preserve the base formula, map the selected fixed literal to its witness mate, and preserve all earlier prefix units. Members are applied in their certified order as ordinary add_sr steps.

Graph-symmetry fixing

colored CNF incidence graph → candidate signed permutation π check polarity, bijectivity, live variables, and π(F)=F choose representative r in a same-orbit clause C for each other k∈C: X7((r∨¬k),r,h), where h(r)=k add the RUP unit (r)

The graph backend is a discovery mechanism. DSR pivot order is semantic: the representative is first and its explicit mapping overrides the default pivot-to-true mapping. Tactix exact-checks every materialized inverse transversal, checks the live root closure under its witness, and uses the ordered SST prefix to certify earlier cuts. Only after the complete level is present does the representative unit become RUP. An AMO source then propagates the other literals false. Every emitted tuple remains independently checkable DSR.

Composition can expose a useful pure row action even when no backend generator has one directly. The complete lifted word remains exact-checked; group derivation never weakens the X7 obligation.

The added unit chooses one representative of the row symmetry. The exact action supports construction of the finite witness; the resulting tuple still satisfies X7's full guard.

Instantiate

Remove a clause literal whose supporting probe is impossible

public
C=(D∨l)∈F; A={l}∪{¬d | d∈D}; F∧A⊢₁∅ ────────────────────────────────────────────────── X4(C,l) F′ := (F∪{D})\{C}; τ,ρ unchanged

Exact LRAT chain

Walk backward from the successful probe conflict. Sort used reason ids by the trail position of the literal they propagated and append the conflict id last. If that walk depends on the probe decision l, insert C.id at l’s trail position: under ¬D, C replaces the decision by forcing l. Call the resulting list h_D, then emit add_rup(D,h_D)·del(C).

Conflict independent of l

If the reason walk never reaches l, omit C.id. The remaining reasons already refute ¬D, so citing C would be unnecessary and could place a hint after the conflict.

Soundness

The probe proves F⊨¬l∨D; resolving that implication with C=l∨D gives F⊨D. Add-before-delete preserves the exact model set and needs no reconstruction witness.

Ask whether a literal could be the only reason a clause is true. If that situation propagates to conflict, the literal is unnecessary and can be removed.

The candidate replaces the probe decision

C=(l∨a∨b) E₁=(¬l∨q), E₂=(¬q∨a) probe l,¬a,¬b: E₁ forces q; E₂ conflicts D=(a∨b) under ¬D: C forces l, E₁ forces q, E₂ conflicts h_D=[C,E₁,E₂] add_rup(D,h_D); del(C)

The checker does not inherit the probe’s decision l; C must reproduce it as unit propagation.

The conflict does not use l

C=(l∨a∨b) E₁=(a∨q), E₂=(¬q∨b) probe l,¬a,¬b: E₁ forces q; E₂ conflicts D=(a∨b), h_D=[E₁,E₂] [C omitted] add_rup(D,h_D); del(C)

The assumptions ¬a∧¬b already conflict independently of l, so the original clause is not an antecedent of the RUP addition.
