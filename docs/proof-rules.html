M1

Propagate

Run Boolean constraint propagation to conflict or fixpoint

public
F not refuted ∧ no unresolved conflict ∧ τ not at BCP fixpoint ────────────────────────────────────────────────────────────── M1 ⟨F,R,τ,ρ,π⟩ → ⟨F,R,τ·forced,ρ,π·δ⟩

Effect

Assign every forced literal at its true level. Stop at the first conflict or at fixpoint; a root conflict returns Unsat.

Proof δ & soundness

add_derived_unit for root units under LRAT; add_empty for a root conflict. BCP assigns only consequences of F ∧ M.

Follow implications until nothing else is forced. If a clause has one possible literal left, that literal must be true. If every literal in a clause becomes false, propagation has found a conflict.

A root implication

F = {(a), (¬a ∨ b)} τ = [] ⇒ τ′ = [a@0, b@0]

The unit a forces b. LRAT records both derived root units.

A root contradiction

F = {(a), (¬a)} ⇒ a@0 and ¬a@0 ⇒ ∅, Unsat

The empty clause is RUP from the contradictory units.

M2

Decide

Choose any unassigned literal and open a search branch

public
x unassigned ∧ no unresolved conflict ∧ F not refuted ────────────────────────────────────────────────────── M2(l) dl := dl+1 ; τ := τ · (l@dl, reason=DECISION) δ = ε

Instance

Any unassigned literal and phase. No propagation-fixpoint requirement exists in the abstract calculus.

Soundness

A decision is a case split, not a logical inference; it changes only the explored branch.

Make a reversible guess. Decide does not claim the literal follows from the formula, so it emits no proof line. A later conflict can undo the branch.

Positive phase

F = {(a ∨ b)}, τ = [] Decide(a) ⇒ τ′ = [a@1(decision)]

The clause is satisfied on this branch; no proof delta is emitted.

Choose the other phase

F = {(a ∨ b)}, τ = [] Decide(¬a) ⇒ τ′ = [¬a@1] M1 then forces b@1

N1 exposes both a and ¬a as legal instances.

M3

ConflictAnalysis

Learn a 1-UIP clause and backjump atomically

public
Cconflict is all-false under M ∧ F not refuted ──────────────────────────────────────────────── M3 derive L₁UIP ; R := R ∪ {L}; backtrack(j); assert UIP δ = add_rup(L, antecedents) · optional del(...)

Effect

Analyze, minimize, optionally strengthen by OTFS, learn, backtrack, and assert in one public transition. Root conflict yields ∅.

Soundness

The learned clause is RUP and entailed by the conflict reasons; assertion at the jump level is ordinary unit propagation.

Explain why the current branch failed, remember the explanation, and jump to the earliest useful point. The new clause prevents the solver from repeating the same conflicting combination.

Learn the negated decision

(¬a ∨ b), (¬a ∨ c), (¬b ∨ ¬c) Decide a@1 ⇒ b@1, c@1 ⇒ conflict Resolve reasons ⇒ L = (¬a) Backjump 0; assert ¬a@0

The three-clause implication pattern proves that choosing a can never work.

Root refutation

(p), (¬p ∨ q), (¬p ∨ ¬q) p@0 ⇒ q@0 and ¬q@0 Analyze ⇒ L = ∅ ⇒ Unsat

At root there is no lower level to revisit, so M3 emits the empty learned clause.

M4

Backjump

The folded tail of M3, not a separately schedulable rule

folded
M3 has learned asserting clause L with jump level j ──────────────────────────────────────────────────── M4 (inside M3) truncate τ to target t ∈ [j, level−1]; assert UIP at true level j δ = ε

Status

No public guard, instances, or apply surface. The target is an M3 instance parameter.

Soundness

Removing trail assignments is safe; the learned clause forces its UIP at j even if chronological backtracking retains higher decisions.

Undo only as much search as the learned clause requires. Tactix exposes this choice through ConflictAnalysis rather than allowing a half-finished learned clause to escape between two rules.

Canonical non-chronological jump

current level = 5 learned L has second-highest level j = 2 target t = 2 ⇒ remove levels 3..5; assert UIP

The clause becomes unit exactly at its standard jump level.

Chronological target

current level = 5, j = 2 choose target t = 4 ⇒ retain levels 3..4 assert UIP with true level 2

The extra decisions remain, but the assertion keeps the logical level determined by its reason.

S1

Restart

Discard a trail suffix while keeping learned knowledge

public
F consistent and not refuted ────────────────────────────── S1(k) ⟨F,R,τ,ρ,π⟩ → ⟨F,R,prefixₖ(τ),ρ,π⟩ δ = ε

Effect

Drop to a chosen keep level; clauses and proof state stay unchanged.

Soundness

Removing temporary assumptions cannot remove or create formula models.

Start searching from a shallower point without forgetting learned clauses. Restarts change the route through the search tree, not the formula.

Full restart

τ = [u@0, a@1, b@2, c@3] Restart(0) ⇒ τ′ = [u@0]

Only root facts survive.

Prefix restart

τ = [u@0, a@1, b@2, c@3] Restart(1) ⇒ τ′ = [u@0, a@1]

A partial restart keeps the first decision branch.

S2

Reduce

Forget selected redundant learned clauses

public
F not refuted ∧ D ⊆ R ∧ no d ∈ D is reason-locked ────────────────────────────────────────────────── S2(D) R := R \ D ; δ = ∏ d∈D del(d)

Effect

Delete selected learned clauses, compact storage, and forward surviving trail reasons.

Soundness

Every deleted clause is redundant/entailed; proof checkers accept deletions without a chain.

Throw away learned hints that are no longer worth their memory cost. The original problem clauses stay; a clause currently explaining an assignment is protected.

Forget a weak learned clause

R = {(a ∨ b), (c ∨ d ∨ e)} D = {(c ∨ d ∨ e)} ⇒ R′ = {(a ∨ b)} δ = del(c ∨ d ∨ e)

The solver may need to rediscover it later, but satisfiability is unchanged.

Protect a live reason

reason(x) = (x ∨ ¬a) candidate D contains reason(x) ⇒ skip that clause

Deleting it would leave the current trail with a dangling explanation.

S5

Lucky

Try a complete assignment and report SAT only on success

public
F consistent and not refuted ──────────────────────────────────────── S5 complete assumption assignment A if A ⊨ F: Sat(A) ; otherwise restore σ exactly δown = ε

Effect

Success leaves a total model. Failure restores the entry state. Root closure performed at entry may still emit units or refute.

Soundness

SAT is returned only after every clause is satisfied by a total assignment.

Try to get lucky with a full phase assignment. If it works, the solver has a model. If not, the speculative attempt is erased as though it never happened.

A lucky model

F = {(a ∨ b), (¬a ∨ b), (a ∨ ¬b)} try A = {a=true, b=true} A ⊨ F ⇒ Sat

All three clauses are satisfied.

A failed attempt

F = {(a ∨ b), (¬a ∨ b)} try A = {a=true, b=false} conflict ⇒ restore σ

The rule does not learn from its own failed guess; ordinary search continues from the original state.

C1

SubsumeForward

Delete a clause covered by a stronger live clause

public
d,c ∈ F live ∧ d ⊆ c ──────────────────────── C1(d,c) F := F \ {c} ; δ = del(c)

Precondition

The subsumer d is irredundant/live. The victim need not be restricted for soundness.

Soundness

d ⊨ c, so keeping both imposes exactly the same models as keeping only d.

A shorter clause makes a longer superset useless. Any assignment satisfying the shorter clause already satisfies the longer one.

Direct subset

d = (a ∨ b) c = (a ∨ b ∨ c) d ⊆ c ⇒ delete c

The literal c adds no constraint.

Binary subsumer

d = (¬x ∨ y) c = (¬x ∨ y ∨ z ∨ w) ⇒ del(c)

Binary clauses have an irredundant lifecycle in this calculus.

C2

Strengthen

Remove a literal by self-subsuming resolution

public
c = (x ∨ A), d = (¬x ∨ B), c′ = A ∪ B, c′ ⊂ c ───────────────────────────────────────────────────── C2 F := (F ∪ {c′}) \ {c} δ = add_rup(c′,[c,d]) · del(c)

Effect

Add the smaller resolvent before deleting its parent. Unit and empty results assert or refute.

Soundness

The resolvent is RUP from its two parents; add-before-delete preserves proof availability.

Use another clause to prove one literal in a clause is unnecessary. The replacement is strictly stronger and checker-verifiable.

Drop a pivot literal

c = (x ∨ a ∨ b) d = (¬x ∨ a) resolve x ⇒ c′ = (a ∨ b) add c′; delete c

The resolvent is a strict subset of c.

Collapse to a unit

c = (x ∨ a) d = (¬x) resolve x ⇒ c′ = (a) ⇒ assert a@0

A strengthening can expose a new root fact.

C3

Vivify

Distill a clause through speculative propagation

public
c ∈ F ∧ propagation under negated prefix proves c′ ⊂ c ──────────────────────────────────────────────────── C3 F := (F ∪ {c′}) \ {c} δ = add_rup(c′, reason-chain) · del(c)

Outcomes

Strengthen, delete a root-satisfied clause, assert a surviving unit, or refute on empty distillation.

Soundness

The speculative conflict supplies the RUP chain for the shorter clause.

Try falsifying a clause from left to right and watch what propagation proves. If conflict arrives early, the untouched suffix was unnecessary.

RUP shortening

C = (a ∨ b ∨ c) other: (a ∨ d), (b ∨ ¬d) assume ¬a, ¬b ⇒ d and ¬d ⇒ add (a ∨ b); delete C

The conflict occurs without needing literal c.

Strip a root-false literal

C = (a ∨ b ∨ c) root has ¬a ⇒ C′ = (b ∨ c) add C′; delete C

The root unit permanently falsifies a.

V1

Probe

Derive root units by refuting an assumed literal

public
p unassigned ∧ F ∧ M ∧ p ⊢₁ ∅ ─────────────────────────────── V1(p) F := F ∪ {(¬p)} ; δ = add_rup((¬p), conflict-chain)

Effect

Test candidates with full propagation, collect each failed literal’s negation, then assert the batch at root.

Soundness

If assuming p unit-propagates to conflict, F ∧ M ⊨ ¬p.

Temporarily try a literal. If propagation immediately proves that choice impossible, its opposite is a permanent fact.

Two opposing implications

(¬p ∨ q), (¬p ∨ ¬q) assume p ⇒ q and ¬q ⇒ add (¬p)

The failed assumption becomes a root unit.

Conflict through a long clause

(¬p ∨ a ∨ b), (¬a), (¬b) assume p ⇒ clause becomes empty ⇒ add (¬p)

Full Probe sees non-binary clauses, unlike V2.

V2

Backbone

Run failed-literal probing using only the binary graph

public
p unassigned ∧ BIG(F) ∧ p ⊢₁ ∅ ──────────────────────────────── V2(p) F := F ∪ {(¬p)} ; δ = add_rup((¬p), binary-chain)

Scope

Identical inference to V1, restricted to permanent binary implications.

Soundness

A binary reason chain is a special case of full unit propagation, so V2’s conclusions are a subset of V1’s.

A cheaper Probe. Follow only two-literal clauses. It finds fewer failed literals but traverses a much simpler graph.

Depth-one failure

(¬p ∨ q), (¬p ∨ ¬q) p ⇒ q and ¬q ⇒ add (¬p)

Both implications are binary edges.

Failure along paths

p→q, q→r, p→s, s→¬r assume p ⇒ r and ¬r ⇒ add (¬p)

The proof chain is the four binary clauses on the two paths.

V3

Substitute

Collapse equivalent literals found as BIG strongly connected components

public
l,r in one non-trivial SCC of BIG(F) ⇒ F ⊨ l ↔ r ──────────────────────────────────────────────── V3 rewrite l↦r in F; eliminate var(l); push equivalence witnesses to ρ δ = add_rup(rewrites, path chains) · del(old clauses)

Effect

Rewrite all occurrences add-before-delete. If x and ¬x share an SCC, emit a refutation.

Soundness

Mutual BIG reachability proves equivalence. Witness pairs let reverse reconstruction recover eliminated variables.

If two literals always imply each other, keep one name. Every clause is rewritten to the representative, and reconstruction remembers how to restore the removed variable.

Simple equivalence

(¬x ∨ y), (x ∨ ¬y) [x ↔ y] (x ∨ z) ⇒ rewrite as (y ∨ z) ⇒ eliminate x, push x↔y witness

The two binaries put x and y in one SCC.

Contradictory SCC

x→y→¬x ¬x→z→x ⇒ x and ¬x in one SCC ⇒ add (x), add (¬x), add ∅

A literal equivalent to its negation makes the formula unsatisfiable.

V4

TransitiveReduce

Delete a binary implication duplicated by another path

public
e = (¬p ∨ r) ∈ F ∧ path p ⟹ r exists in BIG(F)\{e} ────────────────────────────────────────────────────── V4(e) F := F \ {e} ; δ = del(e)

Effect

Delete redundant edges using round-local tombstones so no deletion relies on another edge being deleted in the same round.

Soundness

The surviving path resolves to the removed binary, so the remaining formula entails it.

Remove shortcut edges when a surviving route says the same thing. Reachability stays the same, but the binary graph becomes smaller.

Triangle shortcut

(¬p ∨ q), (¬q ∨ r), (¬p ∨ r) p→q→r duplicates p→r ⇒ delete (¬p ∨ r)

The first two binaries resolve to the third.

Longer alternate path

p→q, q→s, s→t, p→t ⇒ delete direct p→t

The path remains live throughout the round.

V5

Sweep

Discover literal equivalences with a local SAT environment

public
Env is entailed by F Env ∧ a ∧ ¬b ⊢ ∅ and Env ∧ ¬a ∧ b ⊢ ∅ ────────────────────────────────────────────── V5(a,b) F := F ∪ {(¬a ∨ b),(a ∨ ¬b)} δ = add_rup(each direction, replay/core chain)

Precondition

The bounded environment contains proof-identified clauses with root-false literals stripped using their unit IDs.

Soundness

Both implications must replay over the main formula before either binary is emitted.

Ask a small local SAT solver whether two literals can ever differ. If both disagreement cases are impossible—and the main checker can replay them—the equivalence is added.

Equivalence through an intermediary

a↔c encoded by two binaries c↔b encoded by two binaries Env refutes a∧¬b and ¬a∧b ⇒ add a↔b

Sweep materializes the transitive equivalence for later substitution.

Strip a root-false literal

root unit: (¬r) environment clause: (r ∨ ¬a ∨ b) strip r ⇒ (¬a ∨ b), citing (¬r) prove reverse direction too ⇒ add a↔b

Keeping r would make the local clause spuriously easy to satisfy.

V6

Congruence

Equate outputs of structurally identical AND, XOR, and ITE gates

public
F contains complete gates a=f(inputs), b=f(inputs) ────────────────────────────────────────────── V6(a,b) F := F ∪ {(¬a ∨ b),(a ∨ ¬b)} ; unite(a,b) δ = add_rup(equivalence ladders) ρ unchanged

Effect

Close equivalence through union-find. Canonicalization may also derive a unit, unary merge, or smaller gate.

Soundness

All defining clauses must be present: identical Boolean functions on equivalent inputs have equivalent outputs.

Recognize duplicate circuit computations. Once two gate outputs are known equal, gates above them may become duplicates too, so the equivalence cascades through circuit layers.

Duplicate AND gates

o = a ∧ b p = b ∧ a same canonical inputs ⇒ add (¬o ∨ p), (o ∨ ¬p)

Input sorting makes the two definitions identical.

Degenerate gate

o = a ∧ ¬a ⇒ o = false ⇒ add root unit (¬o)

A contradiction among AND inputs collapses the gate to a constant.

V6a

Binary-resolution unit channel

A second inference performed inside V6

internal
(l ∨ o) ∈ F ∧ (l ∨ ¬o) ∈ F ───────────────────────────────── V6a (inside V6) F := F ∪ {(l)} δ = add_rup((l), replayed binary chain)

Effect

Collect derived units with V6’s degeneracy units; contradictory units resolve to empty.

Status & soundness

Not a public rule. Ordinary resolution on o yields (l∨l)=(l).

Whichever value the side literal takes, the other literal must be true. V6 scans binaries for this pattern at linear cost.

Resolve to a unit

(l ∨ o) (l ∨ ¬o) resolve o ⇒ (l) ⇒ assert l@0

The checker chain is obtained by replaying the failed assumption ¬l.

Resolve to contradiction

(l∨o),(l∨¬o) ⇒ (l) (¬l∨p),(¬l∨¬p) ⇒ (¬l) (l),(¬l) ⇒ ∅

Opposite units found in one batch refute the formula.

E1

BVE

Eliminate a variable with bounded Davis–Putnam resolution

public
P=Occ(x), N=Occ(¬x) |non-taut(P ⊗ N)| ≤ |P|+|N|+bound ──────────────────────────────────── E1(x) F := (F \ (P∪N)) ∪ resolvents(P,N) δ = add_rup(resolvents) · del(P∪N) ; push pivot witnesses to ρ

Effect

Add every necessary non-tautological resolvent, then delete all pivot clauses. Gate recognition may avoid only resolvents justified by its unsatisfiable remainder condition.

Soundness

Davis–Putnam elimination is equisatisfiable. Reconstruction witnesses choose a value for x when extending a model backward.

Remove a variable while preserving every consequence between the clauses on its two polarities. BVE is allowed only when the replacement does not grow too much.

One resolvent

(x ∨ a), (¬x ∨ b) resolve x ⇒ (a ∨ b) add (a∨b); delete both pivot clauses push witnesses for x

Any model of (a∨b) can choose an x satisfying the originals.

Tautological cross product

(x ∨ a), (¬x ∨ ¬a) resolvent = (a ∨ ¬a) = ⊤ add nothing; delete both remember x↔¬a through witnesses

The eliminated formula is true, but reconstruction still owes a valid value for x.

E2

Factor

Compress a clause grid by introducing a fresh extension variable

public
G={fᵢ∨rⱼ | i∈[m],j∈[n]} ⊆ F m,n≥2 ∧ mn>m+n ∧ x fresh ──────────────────────────────────── E2(G,x) add {x∨fᵢ} and {¬x∨rⱼ}; delete G δ = add_rat(dividers then quotients) · del(G)

Effect

Replace mn grid clauses by m+n clauses. Delete the grid last.

Soundness & model

Fresh-variable additions are RAT; quotient resolvents are the still-live grid. No ρ witness: project the extension variable out.

Name a repeated rectangular pattern with a fresh helper variable. This is the inverse of eliminating that helper with BVE.

A 2×3 grid

G = {f₁∨r₁,f₁∨r₂,f₁∨r₃, f₂∨r₁,f₂∨r₂,f₂∨r₃} 6 clauses → add: (x∨f₁),(x∨f₂), (¬x∨r₁),(¬x∨r₂),(¬x∨r₃) 5 clauses

The strict reduction condition is 6 > 5.

A 3×3 grid

9 grid clauses ⇒ 3 dividers + 3 quotients ⇒ 6 clauses, net −3

Each quotient’s three RAT resolvents are original grid clauses until deletion.

X2

HyperTernaryRes

Add a short resolvent from two ternary clauses

public
C=(p∨a∨b), D=(¬p∨c∨d) R=(C\{p})∪(D\{¬p}), |R|≤3, R non-tautological, R∉F ────────────────────────────────────────────────────── X2 F := F ∪ {R}; δ = add_rup(R,[C,D])

Effect

Add one new binary or ternary resolvent; delete nothing.

Soundness

Resolution entails R. Negating R makes one parent force p and the other conflict.

Resolve two three-literal clauses when their overlap keeps the result short. The added clause can make later propagation stronger.

Ternary result

(p ∨ a ∨ b) (¬p ∨ b ∨ c) resolve p ⇒ (a ∨ b ∨ c)

The shared b keeps the union at size three.

Binary result

(p ∨ a ∨ b) (¬p ∨ a ∨ b) resolve p ⇒ (a ∨ b)

Both non-pivot sides coincide.

X6

HyperBinaryRes

Derive a binary from BIG paths that falsify the rest of a clause

public
C=(l₀∨l₁∨…∨lₖ), k≥2 ∀i>0: BIG(F) contains d ⟹ ¬lᵢ ────────────────────────────────── X6(C,l₀,d) F := F ∪ {(¬d∨l₀)} ; optionally del(C) if (¬d∨l₀)⊆C δ = add_rup(binary,replay-chain) · optional del(C)

Effect

Add the binary implication d→l₀; delete the source clause only when the binary subsumes it.

Soundness

Under d∧¬l₀, BIG paths falsify every other literal, so C conflicts.

If one condition makes every alternative in a clause false, it must force the remaining literal. Record that fact as a new binary clause.

Derive a new implication

C=(u∨a∨b) d→¬a and d→¬b ⇒ add (¬d∨u)

When d holds, only u can satisfy C.

Derive and subsume

C=(u∨¬d∨b) d→¬b ⇒ R=(¬d∨u) R⊂C ⇒ add R; delete C

The new binary makes the longer source clause redundant.

X1

BCE

Delete a clause blocked on one of its literals

public
C∈F, l∈C, and every resolvent of C with D∋¬l is tautological ────────────────────────────────────────────────────────── X1(C,l) F := F \ {C}; ρ := ρ · (l,C); δ = del(C)

Effect

Delete the blocked irredundant clause and push its blocking-literal witness.

Soundness

A model of F\{C} that falsifies C is repaired by setting l true; tautological resolvents protect every ¬l-clause.

A clause is removable when flipping one chosen literal can always repair it without breaking its opponents. The witness records that repair.

One opposing clause

C=(x∨a) D=(¬x∨¬a) resolve x ⇒ (a∨¬a)=⊤ ⇒ C blocked on x; delete C; push (x,C)

If a model later falsifies C, set x true.

Two tautological resolvents

C=(x∨a∨b) D₁=(¬x∨¬a) D₂=(¬x∨¬b) both x-resolvents tautological ⇒ delete C

Each clause opposing x contains a literal protected by the flip.

X3

CCE

Grow a clause by ALA/CLA until it is blocked or asymmetric-tautological

public
C=C₀⊆C₁⊆…⊆Cₙ ALA: add ¬d when D\{d}⊆Cᵢ CLA: add intersection I at pivot u∈Dᵢ exit: Cₙ blocked, or ∃Q∈F\{C}: Q⊆Cₙ ──────────────────────────────────────────── X3 delete original C; push CLA witnesses in order; add final blocked witness δ = del(C) ; ρ updated (ATA without CLA needs no witness)

Effect

The grown clause is a reasoning device; the original clause is what gets deleted.

Soundness

ALA closure links the larger tested clause to smaller recorded witness segments; reverse replay repairs CLA steps and then the deleted clause.

Temporarily enrich a clause until BCE-style removal becomes visible. ALA adds forced complements; CLA adds literals common to all relevant pivot partners. Reconstruction unwinds the recorded covering steps backward.

ALA then blocked

C₀=(a∨b) D=(a∨d) gives ALA literal ¬d C₁=(a∨b∨¬d) E=(¬b∨d) resolve C₁,E on b ⇒ contains d∨¬d ⇒ C₁ blocked on b; delete C₀

The original clause was not blocked on b; its ALA extension is.

CLA then ATA exit

C₀=(u∨a) u-partners: (¬u∨b), (¬u∨b∨c) intersection I={b} D₁=(u∨a∨b) Q=(a∨b) ⊆ D₁ [ATA exit] ⇒ delete C₀; push (u,C₀)

The common covered literal b makes the extension asymmetric-tautological.

X4

Instantiate

Remove a clause literal whose supporting probe is impossible

public
C=(D∨l) ∈ F ∧ F ∧ l ∧ ¬D ⊢₁ ∅ ──────────────────────────────────── X4(C,l) F := (F ∪ {D}) \ {C} δ = add_rup(D, reason-chain including C) · del(C)

Effect

Add the clause without l, then delete its superset.

Soundness

Under ¬D, the original clause forces l, reproducing the failed probe; therefore D is RUP from F alone.

Ask whether a literal could be the only reason a clause is true. If that situation propagates to conflict, the literal is unnecessary and can be removed.

Shorten a ternary clause

C=(l∨a∨b) other clause: (¬l∨a) assume l,¬a,¬b ⇒ (¬l∨a) false ⇒ add (a∨b); delete C

Equivalently, resolving the two clauses on l yields (a∨b).

Collapse to a unit

C=(l∨a) other clause: (¬l∨a) assume l,¬a ⇒ conflict ⇒ add (a); delete C

The remaining literal becomes a root consequence.
