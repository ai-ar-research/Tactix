# AM464: production split-unit DSR transaction checkpoint

Date: 2026-09-26. Parent `3e7f3143`; source patch archived as `benchmarks/probes/scratch/am464-split-production/pin-final/source.patch.gz` (uncompressed SHA-256 `414d815a4d1312f0da23cdc708840bfe6437750be10eff3abc63716874cea7e0`). This is a focused N2 repair checkpoint, not combined N1–N4 acceptance.

The native DSR serializer now stages each RUP unit until the next addition or flush. If deletions follow, it first writes two RUP supersets `(u ∨ a)` and `(u ∨ ¬a)`, writes all intervening deletions, writes `u`, then deletes both supersets. The auxiliary uses an external identity beyond the currently known input/proof variables and may be reused after retirement. Each helper is RUP at the original unit point; after the deletions, the helpers force a contradiction under `¬u`, so `u` remains RUP independently of which reasons the checker retains. The transaction is shared by every ordinary DSR RUP-unit producer, with no public X7 guard change and no checker option or status change. Probe's support-cone walk and support-specific proof API were removed because this transaction no longer needs them. DRAT/LRAT bytes retain their previous path.
