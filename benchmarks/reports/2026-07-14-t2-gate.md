## §5.4 revamp evaluation

**Verdict: no revamp warranted at this gate.** The day's entire
phase-2 load — the API v1 freeze with a generic instance surface,
two new rule families, the kissat restart package, chronological

packing — the candidate already on file, to be evaluated against
Tier C profiles in phase 3, where inprocessing will reshape clause
databases anyway.
