# AM366: DejaVu component-adjacency regression strengthening

Date: 2026-09-24. This checkpoint changes only `tests/test_symmetry_backend.cpp`; the solver behavior remains the AM364 candidate `2c42a6d5`, whose frozen Opus campaign is running. It does not accept N1--N4 or submit Tier D.

AM364 fixed DejaVu's `graph_decomposer::decompose` by recording each compacted adjacency length in `g->d[v]`. Its original causal fixture used two separate two-vertex color cells connected through a singleton-color bridge. The bridge is pruned from each component and both component degrees must become zero; the fixture fails against the old vendored backend and passes with the repair.

The fixture now checks the complementary case too. It adds an internal edge to each two-vertex color cell while preserving the singleton-color bridge. Each output component must still have exactly two vertices, but now both degrees must be **one**, and each sole adjacency must be the other translated component vertex. The same test function iterates the zero-internal-edge and one-internal-edge cases, so neither over-pruning nor under-pruning can pass. This is a graph-invariant test, not a CNF-specific route.
