# AM474: native-DSR Rank 7 performance repair

The Rank 7 automatic-proof timeout was a proof-emission cost, not a SAT search failure or checker-contract problem. On the original 29,068,414-variable CNF, a corrected 120-second `perf` sample of the pinned `ab879129` CLI (`1729118`, 12,000 samples, zero lost) attributed 99.24% of sampled user cycles to `Proof::external_variable_bound()`. The CLI bound `internal_to_external` but omitted `external_to_internal`; each pending DSR root-unit/deletion flush therefore scanned the full internal map to choose a fresh proof-only auxiliary. The API and parser replay paths already bound both maps. The stable external map grows with every permanent external identity and retains retired ones, so its size supplies the same bound in constant time.

`src/main.cpp` now binds both maps when enabling a CLI proof. It does not alter the DSR transaction, legal X7 actions, automatic content route or any checker option. The standalone Release solver SHA-256 is `c57482f1551e48b6f460398790b605b75cb9149e96d38e8406e2b1f2b5315631`; the independent Debug/ASan+UBSan build and Release `test_proof` serializer passed, with Debug `test_proof` passing under `ASAN_OPTIONS=detect_leaks=0` because LeakSanitizer cannot run under the session ptrace wrapper.

Matched Rank 7 SLURM array `1729380` used 12 CPUs, 32 GiB, the same original compressed input SHA-256 `4920ce60aefe5f8ed848075ed8186398ca8278f0249170a18d130d58882d82d9`, and a 300-second solve cap. Decompression happened before timing. Native DSR solved SAT in **76.443 s** and AUTO solved SAT in **75.495 s**; both original-CNF models passed frozen `checkmodel` SHA-256 `5fde6bbc...` (78,481,932 clauses, 29,068,414 assigned variables). Both emitted byte-identical 1,171,589,826-byte proofs, SHA-256 `fdcdfe48991dc5e6a929c7267dd564c1e8c138e558885bcca995483077f2a716`. These SAT proofs are output artifacts, not UNSAT certificates to score. Both tasks completed successfully in 2:46/2:37 total allocation time.

For comparison, matched prior diagnostic `1729069` solved the same SAT row with no proof in 62.646 s and DRAT in 59.483 s, with independently checked models; old `ab879129` AUTO timed out at 300.017 s. Old explicit DSR `1729079` timed out at 300.018 s, and immediate pre-AM472 `1d81d353` DSR `1729097` timed out at 300.018 s. A September known-good no-proof pin solved in 54.043 s with a checked model. This repair removes the measured native-DSR bottleneck on Rank 7, but the full Phase 1 Rank gate remains failed on the old-source array; one case cannot establish the 50/50 aggregate or all N1–N4 gates. Latest-source Opus AM473 fuzz and full Debug `1729059` remain separate in-flight evidence. Tier D is not authorized.
