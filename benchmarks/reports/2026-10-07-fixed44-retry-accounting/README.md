# Fixed-44 coverage and immutable retry accounting

`tools/bench/score_fixed44.py` checks the exact frozen 44-instance selection, candidate binary, argument vector, matrix and pin hashes. It counts only clean, independently checked SAT/UNSAT records within the fixed proof deadline. A reported verified result cannot hide an abnormal checker exit, timed-out stage or pipeline overrun. Resource incompleteness, missing records, proof censors and rejected checks never close an instance; they suppress complete-arm PAR-2.

A retry retains the full matrix and original task identities. Its allowed tasks must refer to hash-bound, retryable `scratch_node_busy` records. The scorer merges immutable attempts only when source, solver, options, checker/runner pins and inputs agree. It rejects changed candidates, wrong predecessor hashes and attempts to replace an already verified row. All attempts remain in the output. Reaching twelve verified results is explicitly coverage only, never N1–N4, fuzz, Debug or regression acceptance.

Seventeen directed tests pass, including forged verification flags, missing/replaced instances, abnormal checker exits, delayed verification, changed binary bytes, mixed candidate retries and attempts to double-count a verified result. `tests.txt` retains the test output.
