This is a bounded source/trace audit of that handoff, not a change to the AM486 oracle, the public action contract, X7 legality, or any proof checker. AM486 independently verified every reached model and certificate and found no X7-specific divergence in 93,000 fresh programs; see its terminal `REPORT.md` and `handoffs/H1-post-solve-strict-state.md`.

For **11 of 12** rows, both writers first report SAT with a valid identical model, but the SAT producer is different. Proofless terminates immediately after the early proof/model opportunities, at search levels 5–16. LRAT skips the structured-root program, then reports `lucky_early_end sat` at levels 1–3. In `src/policies/default_policy.cpp`, the structured-root-before-Lucky program is explicitly available only with no proof or native DSR; if it returns SAT, `solve` terminates there. The compatibility writer instead proceeds to early Lucky. The concrete seed `486113775` ends the first solve at level 8 proofless versus level 1 LRAT with the same 14-literal model. Its subsequent public Restart enumerates `7/9` versus `0/2` keep-level instances. This is the expected consequence of distinct legal SAT-producing paths; the parent source reproduces this bounded seed’s twin difference.

Seed `486173611` is the remaining row. Both first-SAT prefixes return the same 86-literal model and identical public solve counters, but a boundary-only event trace already differs at `preprocess_begin`: proofless has 84 active variables / 333 irredundant clauses, LRAT has 85 / 340. The public preceding X7 operations both return `NoChange` and the random non-X7 operations print the same lines. This proves a pre-SAT hidden state difference on the pinned source, but this audit does not attribute its exact producer. Its post-SAT Restart is therefore not evidence that the X7 status repair changed search state.

The AM486 classifier hashes public values only while status is unknown; it first observes these terminal-state differences at the next state-dependent `R` action. Requiring identical Restart instances after two proof-format-dependent SAT paths is stronger than the X7 no-op/status contract. Do not relabel AM486's frozen 12 failures. For a future affected-scope campaign, freeze an oracle that compares X7 actions and proof/model outcomes through the first terminal solve, records later cross-writer action-state comparisons as explicit noncoverage, and tests postterminal C-API legality and soundness per writer separately. The canonical DSR→LSR→Trestle route and all checker options remain unchanged. If cross-format *post-SAT search-state identity* is instead adopted as a new public contract, it needs a policy-level design and performance assessment, not a local X7 patch.

This classification supports running the separately pinned AM487 Phase 1 performance gate on unchanged `0ed8b564`: no AM486 finding requires a source repair, and the only frozen failure concerns postterminal cross-writer action-state identity. It does **not** satisfy AM486 acceptance or the combined N1/N2 goal; a newly frozen affected oracle with explicit terminal-state scope is still due.
