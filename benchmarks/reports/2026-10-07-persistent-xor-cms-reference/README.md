# Pinned CryptoMiniSat Gaussian scheduling reference

Primary source is pinned by commit and per-file hashes in bindings.json.
GaussConf source sets100000 rows/columns and usefulness0.2 with minimum200
calls and check cadence1024, unlike the older smaller README defaults. This
reference corrects proposed Default integration ceilings; dimensions remain
bounded by admitted input, work and retained-byte budgets. Pinning source is
not an N4 parity or performance acceptance claim. Incremental matrix and
component scheduling still need explicit implementation/deviation review.
