Tactix's `kernel_push_witness` and `kernel_extend_model` currently store and replay exactly one witness literal per removed clause. The existing §16 reasoned no-implement disposition explains this representation gap; it does **not** make the literal goal “all proof rules in CaDiCaL/Kissat/winners” true. X5 remains outstanding until implemented and validated or the user explicitly narrows that goal.

This audit did not find an additional *confirmed* missing generic winner proof primitive among three distinctive source mechanisms reviewed. The frozen Satsuma+Kissat launch script invokes `satsuma fix --bsr --proof-file`; Tactix X7 accepts an explicit finite substitution witness and emits native DSR (`src/rules/substitution_redundancy/substitution_redundancy.cpp:652`), though full X7 acceptance remains pending. Kissat-style Factor's fresh-variable RAT grid is implemented by Tactix E2 (`src/rules/factor/factor.cpp:708` onward); generic definitional extension beyond that grid remains a separately proposed rule in `docs/design/phase-4.20-proof-rule-survey.md`, not a demonstrated winner-only default operation. ## A general X5 rule, not a benchmark shortcut

Let `C` be a live clause and `W` a consistent finite partial assignment represented by literals to set true. For a total model `M`, let `T_W(M)` overwrite exactly the variables in `W`. A general conditional-autarky witness is valid when:

1. `T_W` satisfies `C`; equivalently, some literal of `C` is in `W` (assuming a non-tautological `C`).
2. For **every other live clause** `D`, including redundant clauses and every binary copy, the local implication `¬C ∧ D ⇒ T_W(D)` holds. This can be decided without SAT search: `¬C` and `¬T_W(D)` are only unit assignments; if they are consistent, check whether any literal of `D` can still be true. Reject if one can. Root-fixed values must be incorporated, and a witness may never overwrite a contrary permanent root value.

If a model of `F \ {C}` already satisfies `C`, reconstruction does nothing. Otherwise it falsifies `C`; rule (1) makes the overwritten model satisfy `C`, while rule (2) preserves each other clause. Thus the deleted formula and original are equisatisfiable, and the exact original-CNF SAT model is reconstructed. Deleting `C` is the proof event in LRAT/DRAT/DSR; no unverified added lemma is needed. The test is content-based and applies to arbitrary clause/cube sizes. With one witness literal it subsumes X1's blocked-clause condition. This proof still needs executable oracle tests on actual Tactix states and every certificate format.

The local-implication guard is a candidate *declared legal instance* definition, not yet shown equivalent to every cube CaDiCaL's producer can discover. Before claiming baseline parity, capture CaDiCaL witness cubes on representative outputs and check that each satisfies this guard, or strengthen the guard to the complete intended global condition. Do not silently narrow X5 to one literal, one clause shape, a benchmark family, or a fixed cube-size limit. Discovery budgets belong to strategy, not the public rule guard.

## Required implementation boundaries

- Extend `ρ` with an ordered, tagged cube segment while preserving existing single-witness segments. Reverse replay must set all `W` literals true only when `C` is false, and interleave correctly with BVE/BCE/CCE/Substitute segments. Use stable external literal identities across compaction and repeated public solves. Add a journal event that records the whole cube without changing production semantics.
- Expose a variable-length `(C,W)` public instance (the existing X7 online v2 structure is the precedent), with transactional input validation and a direct rule application. N1 requires every legal explicit cube, independent of DefaultPolicy's producer or limits. Do not cram a variable-length witness into the v1 `uint64_t` payload.
- Validate the entire live formula, root units, duplicates, retired identities and proof-visible clause state before deletion. Preserve root reason safety and publish no partial proof/reconstruction event if stopped or a resource check fails. General binary and large-clause deletion must each retain all-copy semantics and exact proof IDs.
- Prove old-failing cube cases and single-literal BCE overlap with independent original-CNF model checking, complete UNSAT proof routes in every supported format, negative model/proof controls, and randomized interleavings. Check that X5 does not change the default schedule until an N4-reviewed strategy explicitly enables it. Claude-owned affected fuzz and the combined N1/N2 gates remain required.
