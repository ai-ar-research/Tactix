## Mechanism and boundary

Tactix now separates permanent external variable identities from dense internal
search indices. The kernel compacts retired variables only after their
formula-changing retirement work is complete; compaction itself only remaps
representation and emits no proof delta. Clauses, watches, binaries, arena
references, trail/reasons, per-variable kernel state and `H` move together.
Proofs, models, reconstruction, rule-instance payloads and the C API retain
external identities.

The kernel exposes the formula-neutral primitive and its safety preconditions.
`DefaultPolicy` owns kissat's scheduling choice: after each Reduce, compact when
inactive variables are strictly more than 10% of the current internal space.
`TACTIX_NO_COMPACT=1` supplies the paired off arm. No proof rule or guard reads
that choice.

the three windows above use only that corrected pin.

## Decision

Ship compaction enabled. The port matches kissat's default mechanism and
trigger, preserves the proof-rule/strategy boundary, is correctness-clean,
ties Tier A, helps robustly on Tier B, and is broadly favorable on Tier C once
its single trajectory cliff is removed. `mp1-Nb5T15` remains an ordinary
trajectory-sensitivity datum; it does not justify a benchmark-specific gate.
